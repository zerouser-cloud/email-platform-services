# Phase 999.12 Plan 02: Foundation REDIS_CLIENT Public Surface Summary

Foundation cache module now exposes `REDIS_CLIENT` (Symbol DI token) through both the public barrel AND `DynamicModule.exports` array, plus re-exports the `ioredis` `Redis` type aliased as `RedisClient` — pre-staging the foundation API change for Plan 10's gateway throttle migration to `@nest-lab/throttler-storage-redis`.

## Objective Recap

Per RESEARCH §S-3, two foundation files needed coordinated edits so `REDIS_CLIENT` is both **importable** from `@email-platform/foundation` and **resolvable through DI** when an app imports `CacheModule`. Without both edges, downstream Plans 04-09 (per-service AppCacheModule re-exports) and Plan 10 (gateway throttle migration) face a coupled multi-step risk.

This is a narrow, documented amendment to **Phase 21 D-04** ("REDIS_CLIENT остаётся приватным"). The compensating control is **ESLint Override 4** (Phase 999.12 D-08, applied in Plan 01) which textually bans `from 'ioredis'` in `apps/*/src/**` — even an app that resolves `REDIS_CLIENT` cannot ergonomically call ioredis methods without violating lint. The SPIRIT of D-04 (apps cannot reach into raw client) is preserved while enabling the one legitimate library-owned consumer.

## Final Shape — `cache.module.ts`

```typescript
import { Module, type DynamicModule } from '@nestjs/common';
import { TerminusModule } from '@nestjs/terminus';
import { CACHE_SERVICE, REDIS_HEALTH, REDIS_CLIENT } from './cache.constants';
import type { CacheModuleOptions } from './cache.interfaces';
import { cacheProviders } from './cache.providers';

@Module({})
export class CacheModule {
  static forRootAsync(options: CacheModuleOptions): DynamicModule {
    return {
      module: CacheModule,
      imports: [TerminusModule],
      providers: [...cacheProviders(options)],
      // Phase 999.12 D-13: REDIS_CLIENT exposed for @nest-lab/throttler-storage-redis (gateway throttle).
      // Phase 21 D-04 amended in 999.12 — narrow public unlock for one library-owned consumer.
      // ESLint Override 4 (Phase 999.12 D-08) blocks raw ioredis imports in apps/* — the
      // regression D-04 was protecting against is structurally prevented at lint time.
      exports: [TerminusModule, CACHE_SERVICE, REDIS_HEALTH, REDIS_CLIENT],
    };
  }
}
```

**`exports:` array** — `[TerminusModule, CACHE_SERVICE, REDIS_HEALTH, REDIS_CLIENT]` (added `REDIS_CLIENT` as the fourth element).
