## Decisions Made

- **Glob style differs by scanner.** Gitleaks and Semgrep use full gitignore syntax including `**` recursive globs, so `scripts/security/fixtures/**` is unambiguous. Trivy's gitignore parser is consistent across `fs` and `config` subcommands for bare paths but not always for `**` — opted for `scripts/security/fixtures` (no glob suffix) to match the most reliable subset of trivy's recursive-prefix behavior, and documented `--skip-dirs scripts/security/fixtures` as the bullet-proof fallback.
- **Trivy 0.50.4 path-glob support: VERIFIED via help output.** `trivy fs --help` confirms both `--ignorefile string  specify .trivyignore file (default ".trivyignore")` and `--skip-dirs strings  specify the directories or glob patterns to skip`. Wave 3 verify scripts will pass an explicit fixture-subdirectory path to `trivy fs <path>` / `trivy config <path>`, which overrides `.trivyignore` per trivy semantics.
- **Comment markers `# Phase 999.17.1` precede every new entry** to make grep-based audits trivial: `git grep -n "Phase 999.17.1" .gitleaksignore .semgrepignore .trivyignore` yields the full set of D-07 path-blocks at a glance.
