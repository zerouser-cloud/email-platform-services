**Delete-only push detection pattern** (RESEARCH §Pattern 4 + Pitfall 3 — no project analog, novel for this phase):

```bash
# Pre-push hook stdin format: <local-ref> <local-sha> <remote-ref> <remote-sha>
ZEROS="0000000000000000000000000000000000000000"
LINE_COUNT=0
ALL_DELETES=true

while read -r local_ref local_sha remote_ref remote_sha; do
  LINE_COUNT=$((LINE_COUNT + 1))
  if [ "$local_sha" != "$ZEROS" ]; then ALL_DELETES=false; fi
done

if [ "$LINE_COUNT" -gt 0 ] && [ "$ALL_DELETES" = "true" ]; then
  echo -e "${GREEN}[INFO]${NC} Delete-only push — skipping pre-push checks."
  exit 0
fi
# else: fall through to orchestrator (handles empty stdin = conservative full chain)
```

**Bash dispatch table (replaces switch/case per `branching-patterns` skill)** (RESEARCH §Pattern 1):

```bash
declare -A AXES=(
  [quality]="pnpm run quality:check"
  [security]="bash -c 'pnpm run security:scan && pnpm run security:verify-if-changed'"
  [hygiene]="pnpm run hygiene:check"
)
```

**Parallel collect-all with per-PID exit array** (RESEARCH §Pattern 2 — explicitly DOC'd at Pitfall 5: `wait $pid; status=$?` does NOT fail-fast under `set -e`):

```bash
declare -A PIDS=()
declare -A EXITS=()

mkdir -p logs
for axis in "${!AXES[@]}"; do
  bash -c "${AXES[$axis]}" > "logs/${axis}.log" 2>&1 &
  PIDS[$axis]=$!
done

for axis in "${!PIDS[@]}"; do
  if wait "${PIDS[$axis]}"; then
    EXITS[$axis]=0
  else
    EXITS[$axis]=$?
  fi
done

# Aggregate — final exit non-zero if ANY axis failed (collect-all, not fail-fast)
final=0
for axis in "${!EXITS[@]}"; do
  status=${EXITS[$axis]}
  if [ "$status" -ne 0 ]; then
    final=1
    echo -e "${RED}[FAIL]${NC} $axis exit=$status — see logs/${axis}.log"
  else
    echo -e "${GREEN}[ OK ]${NC} $axis"
  fi
done
exit $final
```
