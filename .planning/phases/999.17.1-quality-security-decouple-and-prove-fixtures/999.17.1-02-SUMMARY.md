## Decisions Made

- **Image tag stays hardcoded in semgrep-diff.sh.** Centralization via `scripts/security/_versions.sh` is part of Wave 3 verify-script scaffolding (Plan 09 territory). Pulling it in here would expand scope without benefit since this script and the future verify scripts use the same pinned tag.
- **`.semgrep.yml` got the D-12 rejection comment, not the script.** The script already had no `--config auto` reference; the YAML is the canonical "what we use" file, so future readers searching for `auto` in the rulesets configuration land on the rationale immediately.
- **Discovery guard uses two predicates (`[ -d ]` AND `[ -n "$(ls -A)" ]`).** A bare `[ -d .semgrep/rules ]` would pass `--config .semgrep/rules/` even for an empty directory, which Semgrep treats as a configuration error. Two predicates make the discovery a true no-op until Plan 06a populates the directory.
