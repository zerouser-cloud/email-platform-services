```yaml
  - id: no-raw-env-outside-config
    message: |
      Raw `process.env` access detected outside packages/config/. The 12-Factor
      contract requires app code to consume validated config values, never raw
      env-var reads. Move the read into a Zod schema in packages/config/src/.
      See .agents/skills/twelve-factor/SKILL.md.
    severity: WARNING
    languages: [typescript, javascript]
    paths:
      include:
        - 'apps/**'
        - 'packages/**'
      exclude:
        - 'packages/config/**'
        - 'packages/foundation/src/external/config/**'
        - '**/*.test.ts'
        - '**/*.spec.ts'
        - 'scripts/**'
    pattern-either:
      - pattern: process.env.$X
      - pattern: process.env[$X]
    metadata:
      category: best-practice
      technology: [nodejs, typescript]
      project-rule: 'twelve-factor'
```
