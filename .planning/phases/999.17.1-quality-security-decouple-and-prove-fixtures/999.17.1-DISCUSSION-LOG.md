## Quality/Security/Hygiene namespace split (D-2)

### Q1 — Granularity названий в каждой оси

| Option                                                      | Description                                                                                                                                                                                   | Selected |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Atomic по инструменту + meta                                | quality:lint/typecheck/format/check; security:secrets-staged/semgrep-diff/audit-if-changed/.../scan/verify/verify-if-changed; hygiene:env-parity/check; pre-commit/pre-push call meta-scripts | ✓        |
| Только meta по оси                                          | quality:check, security:scan/verify, hygiene:check; can't invoke single scanner; discoverability worse                                                                                        |          |
| Hybrid — atomic для quality, meta-only для security/hygiene | Awkward inconsistency                                                                                                                                                                         |          |

**User's choice:** Atomic по инструменту + meta

### Q2 — Husky pre-commit / pre-push split по осям

| Option                                                                  | Description                                                                                                                                    | Selected |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| pre-commit: quality:staged + security:secrets-staged; pre-push: все три | Quality and Security on pre-commit (<5s); Quality+Hygiene+Security on pre-push (<30s); independent axes — quality fail does NOT block security | ✓        |
| Fail-fast chain                                                         | typecheck error blocks all security gates — exactly the D-2 problem                                                                            |          |
| Quality вынести из hooks (IDE-only)                                     | Developer without IDE plugins pushes broken typecheck; CI catches but after push                                                               |          |

**User's choice:** pre-commit: quality спец-staged + security secrets-staged; pre-push: всё три

### Q3 — Что входит в hygiene:\* помимо env-parity?

| Option                                       | Description                                                                                                  | Selected |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------- |
| Только env-parity сейчас                     | Third axis has 1 inhabitant; future hygiene-checks land in same namespace; expansion hint without commitment | ✓        |
| + check-arch (scripts/check-architecture.sh) | check-arch currently manual; activation = scope creep                                                        |          |
| + check-arch + lockfile freshness            | Adds new invariant to scope                                                                                  |          |

**User's choice:** Только env-parity сейчас

### Q4 — Hook implementation (collect-all vs sequential vs Turbo)

| Option                         | Description                                                                                                                            | Selected |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Параллельный run с collect-all | Background processes + wait + bash array exit codes; developer sees ALL problems in one push (avoids "fix typecheck 5 times in a row") | ✓        |
| Sequential, fail-on-end        | Simpler bash; slower; predictable log order                                                                                            |          |
| Per-axis Turbo task            | turbo currently not invoked from hooks; security tools not turbo-friendly (not packages)                                               |          |

**User's choice:** Параллельный run с collect-all
