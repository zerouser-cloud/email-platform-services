# Phase 999.17.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> See `999.17.1-RESEARCH.md` § Validation Architecture for the source decomposition (gsd-planner finalizes per-task mapping).

---

## Test Infrastructure

| Property               | Value                                                                                              |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| **Framework**          | bash (pnpm scripts) — fixture verification ≠ unit tests; project has `no tests` constraint         |
| **Config file**        | `package.json#scripts` (`security:*`, `quality:*`, `hygiene:*` namespaces — created in this phase) |
| **Quick run command**  | `pnpm run quality:check` (~10-30s — lint + typecheck + format)                                     |
| **Full suite command** | `pnpm run security:verify` (~30-60s — all 6 fixture gates × positive+negative through Docker)      |
| **Estimated runtime**  | quick ~30s, full ~60s after warm Docker cache                                                      |

---

## Sampling Rate

- **After every task commit:** Run `pnpm run quality:check` (lint+typecheck+format)
- **After every plan wave:** Run `pnpm run security:verify` (all 6 fixture gates)
- **Before `/gsd-verify-work`:** Full `security:verify` MUST exit 0 with `6/6 GREEN` matrix
- **Pre-push hook (separate from verify):** orchestrator parallel run with collect-all (quality + hygiene + security:scan + security:verify-if-changed)
- **Max feedback latency:** 60s (full security:verify)
