## Decisions Made

- **Enumerated `files:` arrays over blanket glob.** Both Override 6 and Override 7 list 8 paths individually instead of using `apps/**/clients/**`. Cost: 8-line array per override (still readable). Benefit: zero false positives on HTTP clients, which use the same `*-client.constants.ts` filename pattern legitimately. The pitfall was identified during research; the test (Fixture C) confirmed mitigation works.
- **AST selector with `callee.name="Injectable"`.** Selector targets `CallExpression` inside `Decorator` (i.e., `@Foo()` with parens, not bare `@Foo`). All NestJS decorators use the call form — selector matches them precisely without false positives on other decorator-like syntax (e.g., TypeScript metadata decorators).
- **`git checkout --` for fixture restoration, not `cp` backup.** Atomic single-command rollback; no temp files, no race condition between backup and restore. Post-restore `git diff` returns empty, confirming byte-identical state.
- **Single Rule 3 fix: `pnpm install` for missing plugin.** Worktree node_modules was incomplete (Plan 01 added the dep to package.json + lockfile but the worktree was never `pnpm install`'d). Trigger: lint failure `ESLint couldn't find the plugin "eslint-plugin-check-file"`. Fix: `pnpm install --frozen-lockfile` (469ms). No plan amendment, no scope creep — same dep version (^2.8.0), same lockfile entry.
- **SUMMARY committed BEFORE checkpoint return** (per `<parallel_execution>` worktree contract). Even though Task 4 is incomplete, the agent commits documentation of work done so the parent orchestrator can read it without waiting for human resume.
