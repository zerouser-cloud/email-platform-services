```typescript
export function defineGrpcClient<T extends object>(
  opts: DefineGrpcClientOpts,
  build: (grpc: ClientGrpc, cls: ClsService, deadlineMs: number) => T,
): GrpcClientBuildResult {
  const upperId = opts.service.id.toUpperCase();
  const grpcToken = Symbol.for(`${upperId}${TOKEN_SUFFIX.CLIENT_GRPC}`);
  const healthToken = Symbol.for(`${upperId}${TOKEN_SUFFIX.GRPC_HEALTH}`);

  const facadeProvider: Provider = {
    provide: opts.clientToken,
    inject: [grpcToken, ClsService, ConfigService],
    useFactory: (grpc: ClientGrpc, cls: ClsService, config: ConfigService) =>
      build(grpc, cls, config.get<number>('GRPC_DEADLINE_MS')!),
  };

  const healthProvider: Provider = {
    provide: healthToken,
    inject: [HealthIndicatorService, grpcToken],
    useFactory: (his: HealthIndicatorService, grpc: ClientGrpc) =>
      new GrpcClientHealthIndicator(his, grpc),
  };

  return {
    imports: [
      TerminusModule,
      ClientsModule.registerAsync([
        {
          name: grpcToken,                                    // was opts.grpcToken
          inject: [ConfigService],
          useFactory: (config: ConfigService) => ({
            transport: Transport.GRPC,
            options: {
              url: config.get<string>(opts.service.envKeys.GRPC_URL!)!,
              package: [opts.service.grpc.package, GRPC_CLIENT_HEALTH.PACKAGE],
              protoPath: [
                resolveProtoPath(opts.service.grpc.package, config.get<string>('PROTO_DIR')!),
                require.resolve('grpc-health-check/proto/health/v1/health.proto'),
              ],
              channelOptions: {
                interceptors: [createDeadlineInterceptor(config.get<number>('GRPC_DEADLINE_MS')!)],
              },
            },
          }),
        },
      ]),
    ],
    providers: [facadeProvider, healthProvider],
    exports: [opts.clientToken, healthToken],
    grpcToken,
    healthToken,
  };
}
```

**Critical pitfall to enforce:** `service.id` in catalog is **lowercase** (`'auth'`, `'sender'`, etc. — verified at `packages/config/src/catalog/services.ts:5,11,16,22,33,37`). Existing token names are UPPER (`AUTH_GRPC_HEALTH`). Derivation MUST do `.toUpperCase()` — same convention as `define-service.ts:26`. Skipping this silently breaks DI resolution at runtime.

### Pattern A: 8-Way Replication of Single Refactor

**Source:** `apps/gateway/src/infrastructure/clients/auth/` (treat as canonical reference; verified in research that all 8 upstreams have identical 4-file structure).

**Apply to:** All 8 upstream directories (5 gateway + 3 cross-service).

**Per-directory atomic edit (5 file ops in one commit):**
1. Modify `{name}-client.module.ts` — drop two opts fields, add two named re-exports (D-06).
2. Modify `{name}.client.ts` — strip 2 imports, 2 decorators, convert ClientGrpc to type-only (D-07, D-08).
3. Modify `index.ts` — delete the constants re-export line (D-09).
4. **Delete** `{name}-client.constants.ts` (D-05).
5. Run `pnpm build --filter=@email-platform/{consumer-app}` after each commit — must be green.

**Pitfall 2 enforcement:** All 5 ops MUST be in one git commit per upstream. Splitting across commits leaves intermediate TS-broken state (e.g., constants file deleted while client.ts still imports from it).

### Pattern B: Symbol.for() Token Derivation From Catalog Identity

**Source:** `packages/config/src/catalog/define-service.ts:26,42` — established convention.

**Apply to:** `defineGrpcClient` body — extracts `service.id` (lowercase), uppercases it, applies suffix, wraps in `Symbol.for()`:
```typescript
const upperId = opts.service.id.toUpperCase();
const grpcToken = Symbol.for(`${upperId}${TOKEN_SUFFIX.CLIENT_GRPC}`);
const healthToken = Symbol.for(`${upperId}${TOKEN_SUFFIX.GRPC_HEALTH}`);
```

**Why this works invariantly:** `Symbol.for(key)` consults the global registry — same `key` returns same Symbol regardless of file/realm. So foundation deriving `Symbol.for('AUTH_CLIENT_GRPC')` and apps' previous explicit `Symbol.for('AUTH_CLIENT_GRPC')` resolved to the same Symbol. Refactor preserves runtime DI identity even mid-migration.

**Pitfall 1 / Pitfall 6 enforcement:**
- Always `.toUpperCase()` — `service.id` is lowercase in catalog (`services.ts:5,11,16,22,33`), tokens are UPPER.
- Always `Symbol.for()`, never `Symbol()` — DI lookup uses object identity (`===`).

### Pattern C: Named Re-Export of Factory Result (Encapsulation)

**Source:** Pattern 3 in RESEARCH.md, codified in `.agents/skills/infrastructure-client-layering/SKILL.md` § Anti-Patterns #4.

**Apply to:** All 8 `*-client.module.ts` files.

**Rule:**
```typescript
// CORRECT
export const AUTH_CLIENT_GRPC = grpc.grpcToken;
export const AUTH_GRPC_HEALTH = grpc.healthToken;

// FORBIDDEN — leaks imports/providers/exports
export const grpc = defineGrpcClient(...);
```

Named consts preserve UPPER_SNAKE_CASE convention, grep-ability, and encapsulation (consumer cannot bypass `Module.forRoot()`).

### Pattern D: Decorator-Free Client Class Under useFactory

**Source:** Pattern 2 in RESEARCH.md, codified in `.agents/skills/infrastructure-client-layering/SKILL.md` § Decision Tree Step 3.

**Apply to:** All 8 `*.client.ts` files.

**Rule:** Under `useFactory`, NestJS resolves dependencies via the `inject:` array — `@Inject` on constructor params is ignored, `@Injectable()` on the class is unnecessary. Removing both:
- Eliminates dead code [VERIFIED: NestJS docs § Custom Providers > Factory Providers]
- Resolves the latent circular import (client.ts → constants ← module.ts wanting to re-export them)
- Cleans architectural separation: client = domain facade; module = wiring

**Constructor signature** must match `super()` arity exactly: `(grpc: ClientGrpc, cls: ClsService, defaultDeadlineMs: number)`.

### Pattern E: ESLint Override Block (Self-Modify Same File)

**Source:** `.eslintrc.js:23-119` — 5 existing override entries.

**Apply to:** Adding overrides 6 and 7 to the existing `overrides[]` array.

Each existing override follows shape:
```javascript

```

New overrides match this shape exactly — minimal stylistic divergence from existing 5 entries. Place new entries at end of array (after `apps/*/src/infrastructure/**/*.ts` block).
