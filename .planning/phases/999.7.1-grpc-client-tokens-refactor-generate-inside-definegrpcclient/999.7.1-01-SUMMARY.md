## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Audit grep regex over-broad in plan as-written**
- **Found during:** Task 1 (D-11 audit)
- **Issue:** Plan command (line 105 + verify line 164) uses `grep -E "/(auth|sender|parser|audience|notifier)/"` which matches the parent-app folder segment too — `apps/notifier/...` contains the literal `/notifier/`, so HTTP clients under `apps/notifier/...telegram/...`, `apps/parser/...appstorespy/...`, `apps/sender/...cloud-functions/...` are incorrectly counted (returns 11, not 8). The verification command `test ... -eq 8` would then fail despite the codebase being in the expected state.
- **Fix:** Refined regex to `/clients/(auth|sender|parser|audience|notifier)/` — matches only the second path segment (gRPC client subdirectory). Returns 8 as expected by CONTEXT `<interfaces>` enumeration.
- **Files modified:** None (audit is read-only; fix lives in this SUMMARY's documented commands)
- **Verification:** Refined `find ... | wc -l` returns 8; broad `find ... | wc -l` returns 11 (3 HTTP files captured under section E, confirming they are NOT in gRPC scope).
- **Note for downstream plans:** Plan 05's `check-file/filename-blocklist` rule MUST scope to `apps/*/src/infrastructure/clients/{auth,sender,parser,audience,notifier}/**` (not the broader `apps/{auth,sender,parser,audience,notifier}/**`) to avoid false positives on the three out-of-scope HTTP client constants files (Section E).
- **Committed in:** `c23334a` (this SUMMARY, Task 1 commit)

**2. [Rule 1 - Bug, defensive revert] Foundation lint --fix reformatted unrelated source file during Task 2 verify**
- **Found during:** Task 2 (`pnpm lint` sanity check after install)
- **Issue:** Project's foundation lint script (`packages/foundation/package.json`) runs `eslint "{src,apps,libs,test}/**/*.ts" --fix` — the `--fix` flag is a pre-existing artifact, not introduced by Task 2. Running `pnpm lint` as a verify step caused ESLint to auto-format `packages/foundation/src/external/grpc/clients/define-grpc-client.ts` (multi-line array → single line, lines 60-62). This file is OUT OF SCOPE for Plan 01 (it's Plan 02's primary modification target per Pattern 1) and was not in Task 2's `<files>` declaration.
- **Fix:** Reverted the unintentional reformat with `git checkout -- packages/foundation/src/external/grpc/clients/define-grpc-client.ts` immediately before staging Task 2's commit. This keeps Plan 02's incoming diff predictable and Plan 01's commit exactly matches its declared files.
- **Files modified:** None (reverted to pre-Task-2 state; only `package.json` + `pnpm-lock.yaml` committed in Task 2)
- **Verification:** `git diff --quiet HEAD -- packages/foundation/src/external/grpc/clients/define-grpc-client.ts` clean before Task 2 commit; commit shows exactly 2 files changed (package.json + pnpm-lock.yaml) with no source-file deletions.
- **Note for downstream plans:** No action required from Plan 02. The `--fix` behavior is a project-wide convention; if it becomes a recurring nuisance, consider replacing `--fix` with `--max-warnings 0` in foundation's lint script in a future plan.
- **Committed in:** `d3568a5` (Task 2 commit — the revert ensured the commit matched plan scope)
