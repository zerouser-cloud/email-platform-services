## Sampling Rate

- **After every file edit** (during executor task work, foundation-only): `pnpm build --filter=@email-platform/foundation` + `pnpm lint --filter=@email-platform/foundation` (~15s feedback)
- **After every task commit** (D-10 atomic 1-commit phase): `pnpm build` (full workspace tsc) + `pnpm lint` — both must exit 0
- **After every plan wave** (this phase has 1 wave): `pnpm quality:check` — full lint + typecheck + format-check
- **Before `/gsd:verify-work`:** Full smoke recipe — `pnpm start:native` boots all 6 services to READY + `/health/ready` 200 OK + `pnpm start:isolated` same; both flows must be green
- **Max feedback latency:** 60s for tsc-only feedback; 180s for full quality:check; 300s for cold isolated smoke
