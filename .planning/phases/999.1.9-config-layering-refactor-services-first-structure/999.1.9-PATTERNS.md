## Summary

Фаза 999.1.9 — **structural refactor**, не introduction of new mechanism'ов. Все ключевые паттерны уже живут в codebase (после 999.1.8 + 999.7.x + 999.11.1):

- **Foundation factory (I-3.5)** — `createConfigModule` (упрощается в этой фазе).
- **Narrow-port DI** — 6× *-config.module.ts (999.11.1 Plan 10).
- **Static Zod schemas** — 9× `packages/config/src/schemas/*.ts` (все уже `export const X = z.object({...})` + `type Y = z.infer<typeof X>` — эталон для infra/ и topology).
- **gRPC client pattern reference (999.7.x)** — `defineGrpcClient` factory как symmetry target для config-factory.

999.1.9 расщепляет "identity + topology + env" из централизованного `packages/config/src/{topology,env-schema,catalog/}` на per-app `apps/{name}/`, делает topology статической, убирает intersection-алиасы, вводит `{SVC}_GRPC_PORT`, переводит main.ts на `app.get`-DI.
