# Phase 999.1.9 Plan 04: Auth Service Migration (config per-app layout) — Summary

**Status:** COMPLETE. Task 1 committed (`b7da54b`). Mirrors W3 audience canary pattern verbatim, adapted for auth's simpler case (no peer topologies).

## Goal

Migrate the `auth` service end-to-end to the Phase 999.1.9 per-app config structure. Second proof point after the W3 audience canary — validates that the pattern universally applies to services with NO upstream gRPC clients (no peer topologies to spread). Reduces the set of legacy 2-generic `createConfigModule` call sites from 5 → 4 (sender, parser, gateway, notifier remain on Pitfall 2 escape hatch).

## Key Changes Delivered

### New files (`packages/config/src/apps/auth/`)

- **`identity.config.ts`** — `AUTH = defineService({ id: 'auth', grpc: { serviceName: 'AuthService' } })`. Imports `defineService` via deep relative path (`../../service`) to sidestep legacy re-export collision — verbatim pattern from audience W3.
- **`topology.schema.ts`** — `AuthTopologyShape = { AUTH_PORT, AUTH_GRPC_PORT, AUTH_GRPC_URL }` (terminal leaf per RESEARCH §Pitfall 1 — imports only `zod`).
- **`env.schema.ts`** — native `z.object({ ...AuthTopologyShape, ...DatabaseSchema.shape, ...LoggingSchema.shape, ...GrpcSchema.shape })`. **NO peer topologies** — auth has no upstream gRPC clients. Infra blocks: database, logging, grpc (per PATTERNS.md §Pattern 4 per-service infra table — no Rabbit, no Redis for auth). `type AuthEnv = z.infer<typeof AuthEnvSchema>` (D-08).

### Barrel (`packages/config/src/apps/auth/index.ts`)

Populated from empty stub:
```ts
export * from './identity.config';
export * from './topology.schema';
export * from './env.schema';
```

### Apps

- **`apps/auth/src/main.ts`** (full D-12 + D-16 migration):
  ```ts
  const app = await NestFactory.create(AuthModule, { bufferLogs: true });
  const config = app.get<AuthEnv>(AUTH_CONFIG);
  // ...
  app.connectMicroservice(
    createGrpcServerOptions(SERVICE.auth, config.AUTH_GRPC_PORT, config.PROTO_DIR),
  );
  await app.listen(config.AUTH_PORT, SERVER.DEFAULT_HOST);
  ```
  Dropped: `loadConfig` import, local `AuthEnvSchema` import, `loadConfig(...) as AuthEnv` cast, `SERVICE.auth.grpc.port` literal (replaced by env value).

- **`apps/auth/.../auth-env.schema.ts` DELETED.** Schema now in `@email-platform/config/apps/auth/env.schema` (re-exported via package root).

- **`apps/auth/.../auth-config.module.ts`** — imports `AuthEnvSchema` from `@email-platform/config`; switches from legacy 2-generic `createConfigModule<typeof AuthEnvSchema, AuthEnv>({...})` form to **target single-generic `createConfigModule({...})`** form (no generic args). Narrow ports unchanged (PERSISTENCE + LOGGING — auth has no GRPC_CLIENT because no upstream). Inline docstring updated to reflect the W4 transition.

- **`apps/auth/.../infrastructure/bootstrap/config/index.ts`** — barrel updated; `auth-env.schema` re-export removed with inline migration comment.
