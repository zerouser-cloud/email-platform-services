# Phase 999.1.9 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from 999.1.9-RESEARCH.md §Validation Architecture.

**Project constraint:** «Без тестов — тестирование отдельный следующий этап» (CLAUDE.md Constraints). Валидация для этой фазы — **grep-инварианты + dual-mode runtime smoke gate + build/lint/arch-check**, не unit/integration tests.

## Test Infrastructure

| Property | Value |
|----------|-------|

---

## Sampling Rate

- **After every task commit:** `pnpm lint && pnpm build` (fast, < 30 сек). Pre-commit hook already enforces this.
- **After every wave merge:** `pnpm build && pnpm lint && pnpm check-arch && bash scripts/check-env-parity.sh`.
- **Per-service canary gate (Wave 3 — audience):** Полный dual-mode smoke. **User approval required before proceeding to Wave 4.**
- **Per-service waves 4-8:** build + lint + arch ONLY (canary proved the pattern; сервисы изолированы per-wave).
- **Phase gate (after Wave 11 final verification):** Full dual-mode smoke + все grep-invariants + `/gsd:verify-work`.
- **Max feedback latency:** < 30 сек для per-task; < 5 мин для per-wave smoke.
