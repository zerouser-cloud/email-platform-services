## Research performed

One research call to `general-purpose` agent (2026-04-30, ~117s, foreground):

**Topic:** Idiomatic gitleaks v8 handling для SHA-256 file integrity manifests false-positives, под constraint "no blanket path-allowlist".

**Finding:** `[[allowlists]]` с `condition = "AND"` + `paths` + `regexes` + `regexTarget = "match"` — canonical pattern в gitleaks README (`package-lock.json` example). Discriminate по shape того что найдено, не по path. Sources: gitleaks v8 README, config/allowlist.go, DeepWiki, issues #1919/#1844/#1523, pnpm-lock.yaml community precedent.

**Effect:** D-06 lock'нут с research-backed config snippet.
