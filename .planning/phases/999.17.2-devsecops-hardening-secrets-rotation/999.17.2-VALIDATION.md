## Sampling Rate

- **After every task commit:** Run `pnpm security:secrets-full` for any task touching `.gitleaks*`, `secrets-full.sh`, or planning docs (D-08 cleanup tasks)
- **After every plan wave:** Run `pnpm security:scan` (full meta production scan)
- **Before `/gsd:verify-work`:** `pnpm security:secrets-full` exit 0 + `pnpm start:native` boots + `pnpm start:isolated` boots + smoke `curl :${GATEWAY_PORT}/health/ready` returns 200
- **Max feedback latency:** ~15s for the targeted gate; ~120s for runtime smoke
