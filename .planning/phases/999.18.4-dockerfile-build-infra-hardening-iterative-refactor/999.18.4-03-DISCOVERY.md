## Probe (b) — multi-arch coverage explicit list

**Command:**

```bash
docker buildx imagetools inspect ghcr.io/grpc-ecosystem/grpc-health-probe:v0.4.48 --raw \
  | jq -r '.manifests[] | "\(.platform.os)/\(.platform.architecture)\(if .platform.variant then "/" + .platform.variant else "" end)"'
```

**Output:**

```
linux/amd64
linux/arm64/v8
linux/arm/v7
linux/s390x
linux/ppc64le
```

**Predicate check (must return true):**

```bash
docker buildx imagetools inspect ghcr.io/grpc-ecosystem/grpc-health-probe:v0.4.48 --raw \
  | jq -e '.manifests | map("\(.platform.os)/\(.platform.architecture)") | (any(. == "linux/amd64") and any(. == "linux/arm64"))'
```

**Result:** `true`

**Findings:**

- `linux/amd64` present (CI primary arch).
- `linux/arm64` present (CI secondary arch — covered as `linux/arm64/v8`; `.platform.architecture` is `arm64` regardless of variant, which is what the jq predicate matches).
- Coverage is identical-or-broader than what v0.4.24 ships (per Plan 01's verified facts). No silent arm64 drop.

**Verdict:** PASS — bump preserves multi-arch coverage; no STOP condition.
