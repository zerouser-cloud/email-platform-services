---

## Sampling Rate

- **After every task commit:** Run `docker system df` (~1 s) — captures snapshot to `.planning/notes/docker-cache-bloat-baseline-{TIMESTAMP}.md` after baseline + cleanup tasks.
- **After cleanup task:** Full diagnostic command — proves space was actually recovered (compare against baseline).
- **After daemon.json apply:** `docker info | grep -i 'gc\|builder'` to verify GC policy parsed; smoke `pnpm start:isolated` to prove dockerd restart did not break runtime.
- **Before phase verification:** Regression test from RESEARCH.md §"Регрессионный тест" — 5 cache-busted rebuilds + forced GC trigger; final `docker system df` should be within ±20 % of baseline.
- **Max feedback latency:** ~10 s (diagnostic), ~90 s (smoke), ~5 min (regression).
