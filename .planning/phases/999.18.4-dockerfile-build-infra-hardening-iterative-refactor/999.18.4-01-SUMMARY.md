## Pre-existing Gap Surfaced (Promoted to Plan 02)

Gateway `infra/docker-compose.yml` healthcheck:

```yaml
test: ['CMD', 'wget', '-qO-', 'http://localhost:3000/health/ready']
```

`wget` is not present in distroless `gcr.io/distroless/nodejs22-debian12:nonroot`. Docker engine reports:

```
OCI runtime exec failed: exec failed: ... wget: executable file not found in $PATH
```

Gateway container is silently marked `unhealthy` while the application itself works (verified by direct host curl). Likely regressed during Phase 999.18.3 distroless migration; not caught earlier because no compose dependent service uses `condition: service_healthy` against gateway, and prod k8s probes are independent.

**Promoted to Plan 02** of Phase 999.18.4 (renumbered ahead of version bump and digest pin per user directive — fix immediately so smoke baseline is clean for subsequent plans).
