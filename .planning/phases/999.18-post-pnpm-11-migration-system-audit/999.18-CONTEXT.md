- **D-10:** Cross-check каждое finding против project skills (`.agents/skills/*`) — violation skills блокирует closure phase per memory `feedback_skill_guardrails`.
- **D-11:** Skill guardrails в scope: `runtime-smoke-verification`, `infrastructure-guard`, `infrastructure-client-layering` (Tier 1/2/3 framework), `twelve-factor`, `env-schema`, `gsd-flow-guard`, `no-magic-values`, `branching-patterns`. Findings с цитированием конкретного skill rule.
- **D-12:** Contract generation pipeline placement — отдельный sub-finding в D9. Текущее состояние: `pnpm --filter @email-platform/contracts run generate` запускается в Dockerfile Step 4a внутри каждого сервиса (6 раз × parallel build). Альтернативы: pre-build CI step с commit'ом generated/\* в репу; build once и share через Docker layer; runtime hook. Audit должен оценить trade-offs и рекомендовать canonical placement.

### K8s Future-Destination Awareness

- **D-13:** Pipeline должен быть "правильный с учётом k8s как future destination" не блокируя текущий Coolify deploy. Что мы должны учитывать СО СВОЕЙ СТОРОНЫ (build artefacts, не k8s manifests):
  - Docker image properties (size, layers, multi-arch readiness — arm64 на DigitalOcean nodes часто)
  - Secrets injection patterns — текущий `.env.docker` через docker-compose env_file vs k8s `Secret + envFrom` — наша часть в том чтобы app читал из process.env (это уже соблюдается per twelve-factor)
  - Health probe shapes — `/health/ready` vs `/health/live` separation (k8s readinessProbe vs livenessProbe), startup timing (k8s startupProbe). Текущий стек имеет только `/health/ready` — может потребоваться расщепление.
  - Build determinism — образы должны быть reproducible (same SHA из same lockfile), без host leak (см. Issue #1 как контрпример).
  - Image registry coordination — текущий GHCR (per memory `project_cicd_github`), GitLab миграция планируется (memory `project_gitlab_migration`).
- **D-14:** k8s manifests / Helm charts / Argo CD / k8s networking — НЕ в scope этой фазы. Это DevOps зона, отдельная фаза 999.19+ или DevOps backlog.
