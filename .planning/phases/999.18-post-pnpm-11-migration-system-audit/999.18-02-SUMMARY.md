- **F-24 V1 chosen over V2 (package.json input) based on empirical reproduction class.** The W5 regression was a TRANSITIVE ts-proto bump (pnpm dedup hoisted 2.11.4 → 2.11.6 without any package.json edit). V2 cannot catch transitive bumps; V1 (lockfile-hash) catches them. V3 (globalDependencies) is too aggressive (kills all turbo caches on lockfile change). - **F-14 V1 (TECH-DEBT-LOG with triggers) chosen over architectural rewrites.** F-01 V1 (`syncInjectedDepsAfterScripts: [build]`) mitigates the foot-gun class; F-14 documents the long-term stance per CONTEXT D-03 "осознанный долг" doctrine. V2/V3/V4 all coupled to F-01 V2/V3 rejection or out of audit-and-fix scope.
- **Skill cross-check applied per variant, not just per finding.** 11 ❌ VIOLATES tags applied across rejected V2/V3/V4 variants (e.g., F-01 V4 violates `runtime-smoke-verification` both-flows mandate; F-04 V3 violates two `twelve-factor` rules). Each tag includes the skill name + rule + reason.
