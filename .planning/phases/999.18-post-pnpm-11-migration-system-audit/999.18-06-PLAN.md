**§ Differential test mandate for pre-existing claims (per CONTEXT 999.18 D-09):**

> When a SUMMARY or finding claims a regression is "pre-existing baseline issue (NOT this-wave regression)", the claim is **unverified** until backed by a fail-stop differential test:
>
> 1. `git worktree add /tmp/diff-test <prior-wave-commit>`
> 2. `cd /tmp/diff-test && docker buildx prune --all --force && docker compose build --no-cache --progress=plain <service>`
> 3. Compare PRIOR-wave fail markers vs CURRENT-HEAD fail markers
>
> If PRIOR-wave does not reproduce the failure, the claim is FALSE — the issue IS this-wave regression. Reference: 999.17.3-05-SUMMARY.md §D-W5-04 misclassification (Issue #1 was claimed "pre-existing" but UAT proved it was W5-induced via ts-proto 2.11.4 → 2.11.6 transitive bump).

> Pattern: 3 or more same-day commits with similar subject prefix touching the same file (e.g., 5 prior infra fixes 132138d / fb8dee7 / 6fc9d3c / b9d1913 / da70085 to `infra/docker/app.Dockerfile` within 22 minutes 2026-04-30) is a **patch-density alarm**.
>
> When detected, STOP and:
>
> 1. Switch from /gsd:fast / direct edits to research-mode
