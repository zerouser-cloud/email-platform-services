## Per-Service Verification Recipe (each Plan 1-4)

```
1. pnpm stop:native                              # clean state
2. pnpm stop:isolated                            # ensure isolated also down (port conflicts)
3. pnpm build                                    # TypeScript strict — catches type drift
4. pnpm lint                                     # Prettier + ESLint — catches format drift
5. pnpm start:native                             # infra up + services dev watch
6. wait ~30s for boot                            # Nest "started successfully" log line
7. curl http://localhost:3000/health/ready       # must return 200 with 5/5 upstreams up
8. pnpm stop:native
9. pnpm start:isolated                           # docker-compose full stack with --build
10. wait ~60s for image build + boot
11. curl http://localhost:3000/health/ready      # must return 200 with 5/5 upstreams up
12. pnpm stop:isolated
```

**Checkpoint after each Plan:** ALL 12 steps PASS. Any FAIL → halt sweep, fix forward, do not proceed to next Plan.
