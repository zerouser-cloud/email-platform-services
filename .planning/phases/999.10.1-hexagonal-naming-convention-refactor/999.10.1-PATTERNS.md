### PATTERN A — Controller inbound-port field rename (Plans 1-4)

**Analog:** `apps/auth/src/infrastructure/controllers/grpc/auth.controller.ts` — **the auth controller AFTER Plan 1 is the canonical template for sender/parser/audience**. The auth controller BEFORE Plan 1 is the canonical "from" state for all four files (they share the same `xxxPort: XxxPort` pattern today).

**Current BEFORE shape** (verbatim from `apps/auth/src/infrastructure/controllers/grpc/auth.controller.ts` lines 26-51 — **pre-999.10.1**):

```typescript
@Controller()
@AuthProto.AuthServiceControllerMethods()
export class AuthController implements AuthProto.AuthServiceController {
  constructor(
    @Inject(LOGIN_PORT) private readonly loginPort: LoginPort,
    @Inject(REFRESH_TOKEN_PORT) private readonly refreshTokenPort: RefreshTokenPort,
    @Inject(VALIDATE_TOKEN_PORT) private readonly validateTokenPort: ValidateTokenPort,
    @Inject(REVOKE_TOKEN_PORT) private readonly revokeTokenPort: RevokeTokenPort,
    @Inject(CREATE_USER_PORT) private readonly createUserPort: CreateUserPort,
    @Inject(LIST_USERS_PORT) private readonly listUsersPort: ListUsersPort,
  ) {}

  async login(req: AuthProto.LoginRequest): Promise<AuthProto.TokenPair> {
    const cmd = new LoginCommand(req.email, req.password);
    const result = await this.loginPort.execute(cmd);
    return { accessToken: result.accessToken, refreshToken: result.refreshToken };
  }
  // ... 5 more method stubs, each using this.xxxPort.execute(cmd)
}
```

**Target AFTER shape** (derived mechanically per D-05 row 1):

```typescript
@Controller()
@AuthProto.AuthServiceControllerMethods()
export class AuthController implements AuthProto.AuthServiceController {
  constructor(
    @Inject(LOGIN_PORT) private readonly loginService: LoginPort,
    @Inject(REFRESH_TOKEN_PORT) private readonly refreshTokenService: RefreshTokenPort,
    @Inject(VALIDATE_TOKEN_PORT) private readonly validateTokenService: ValidateTokenPort,
    @Inject(REVOKE_TOKEN_PORT) private readonly revokeTokenService: RevokeTokenPort,
    @Inject(CREATE_USER_PORT) private readonly createUserService: CreateUserPort,
    @Inject(LIST_USERS_PORT) private readonly listUsersService: ListUsersPort,
  ) {}

  async login(req: AuthProto.LoginRequest): Promise<AuthProto.TokenPair> {
    const cmd = new LoginCommand(req.email, req.password);
    const result = await this.loginService.execute(cmd);  // ← only change in body
    return { accessToken: result.accessToken, refreshToken: result.refreshToken };
  }
  // ... 5 more method stubs, each using this.xxxService.execute(cmd)
}
```

**What MUST be preserved (invariant across rename):**
1. `@Controller()` decorator FIRST, `@XxxServiceControllerMethods()` SECOND (Pitfall 1 from 999.10).
2. `implements XxxProto.XxxServiceController` — proto-generated interface.
3. `@Inject(XXX_PORT)` token unchanged (D-03) — tokens retain `_PORT` suffix.
4. Field **type** retains `XxxPort` suffix (D-02).
5. Every method still `async method(req): Promise<X>`, body still builds `new XxxCommand(...)` and calls `this.<field>.execute(cmd)`.
6. Import paths unchanged (no file moves in 999.10.1).

**What MUST change (exactly, mechanically):**
1. Field **name** changes: `xxxPort` → `xxxService` (D-01 runtime-identity rule, D-16 universal). Pattern: camelCase `{verb}{noun}Service` derived from the type stem (strip `Port`, add `Service`).
2. Every **use site** in method bodies: `this.xxxPort.execute(cmd)` → `this.xxxService.execute(cmd)`.

### PATTERN A.edge — Parser abbreviated-form edge case (Plan 3 only)

**Source:** `apps/parser/src/infrastructure/controllers/grpc/parser.controller.ts` lines 38-39.

**Current shape (BEFORE):**

```typescript
@Inject(RUN_STORAGE_SMOKE_PORT) private readonly runSmokePort: RunStorageSmokePort,
@Inject(CLEANUP_STORAGE_SMOKE_PORT) private readonly cleanupSmokePort: CleanupStorageSmokePort,
```

The field names `runSmokePort` / `cleanupSmokePort` are **abbreviated** — they do not match the type stem (`RunStorageSmokePort` → would-be `runStorageSmoke`) nor the proto method names (`runStorageSmoke` / `cleanupStorageSmoke`).

**Target shape (AFTER) — derive from TYPE stem, not from existing short form:**

```typescript
@Inject(RUN_STORAGE_SMOKE_PORT) private readonly runStorageSmokeService: RunStorageSmokePort,
@Inject(CLEANUP_STORAGE_SMOKE_PORT) private readonly cleanupStorageSmokeService: CleanupStorageSmokePort,
```

**Rule:** per D-01 + D-16 universal, field name = `{verb}{noun}Service` where `{verb}{noun}` = camelCase of the type stem (drop `Port`). **Do NOT produce `runSmokeService`** — that would violate D-01 (the runtime-injected class is `RunStorageSmokeService`, not `RunSmokeService`).

**Use sites:** line 136 (`this.runSmokePort`) and line 156 (`this.cleanupSmokePort`) — rename both to `this.runStorageSmokeService` / `this.cleanupStorageSmokeService`.

**Planner callout:** make this edge case **explicit in Plan 3 task description** so the executor doesn't mechanically strip the `Port` suffix and leave the abbreviation intact.

### PATTERN A.collision — Audience method↔field collision showcase (Plan 4)

**Source:** `apps/audience/src/infrastructure/controllers/grpc/audience.controller.ts` line 36 + line 53.

**Current shape (BEFORE):**

```typescript
@Inject(LIST_GROUPS_PORT) private readonly listGroupsPort: ListGroupsPort,
// ...

  // ...
  const result = await this.listGroupsPort.execute(cmd);

```

**Canonical collision case** — the proto method name `listGroups()` and the inbound port's conceptual name (`listGroups`) collide. Without the `Service` suffix the field would have to be `listGroups` (same as method) → compile error OR ugly workaround.

**Target shape (AFTER):**

```typescript
@Inject(LIST_GROUPS_PORT) private readonly listGroupsService: ListGroupsPort,

  // ...
  const result = await this.listGroupsService.execute(cmd);
}
```

**Rule (D-16 universal):** every inbound-port field carries the `Service` suffix, **even without collision** — predictable pattern across all 4 controllers, no case-by-case thinking. This file is the **motivating example** the NAMING.md update (Plan 5) cites.

## Shared Patterns

### Shared Pattern SP-1 — DI token invariance across the rename

**Source:** `apps/auth/src/auth.constants.ts` (Symbol tokens unchanged) + `apps/auth/src/auth.module.ts` (provider bindings unchanged).

**Apply to:** all 4 services during Plans 1-4. **Key insight (RESEARCH.md Risk 1):** NestJS DI resolves by Symbol token, NOT by field name. Provider binding `{ provide: LOGIN_PORT, useClass: LoginService }` has **zero** dependency on the consumer's field name. Field-rename cannot break DI.

```typescript
// apps/auth/src/auth.constants.ts — unchanged through 999.10.1
export const LOGIN_PORT = Symbol('LoginPort');
export const USER_REPOSITORY_PORT = Symbol('UserRepositoryPort');
// ... 5 more tokens, all preserved
```

```typescript
// apps/auth/src/auth.module.ts — unchanged through 999.10.1
providers: [
  { provide: USER_REPOSITORY_PORT, useClass: PgUserRepository },
  { provide: LOGIN_PORT, useClass: LoginService },
  // ... all bindings preserved verbatim
]
```

**Verification grep (planner should embed in each per-service Plan task list):**
- `git diff apps/{svc}/src/{svc}.constants.ts` MUST be empty after Plan N.
- `git diff apps/{svc}/src/{svc}.module.ts` MUST be empty after Plan N.

### Shared Pattern SP-2 — Type annotation invariance (`Port` suffix stays on type)

**Source:** D-02 from CONTEXT.md.

**Apply to:** every controller field rename, every use-case field rename, every service field rename.

**Rule:** field **name** drops `Port` suffix (or gains action-verb per D-05 row 2, or gains `Repository` suffix per D-04). Field **type** keeps its original shape verbatim:
- `loginPort: LoginPort` → `loginService: LoginPort` ← type `LoginPort` **unchanged**.
- `users: UserRepositoryPort` → `userRepository: UserRepositoryPort` ← type unchanged.
- `useCase: CreateCampaignUseCase` → `createCampaign: CreateCampaignUseCase` ← type unchanged.

**Verification grep:**
- `grep -rE "private readonly \w+Service: \w+Port" apps/*/src/infrastructure/controllers/grpc/ | wc -l` MUST equal **31** after Plan 4.

- `grep -rE "private readonly \w+Port: \w+Port" apps/*/src/infrastructure/controllers/grpc/ | wc -l` MUST equal **0** (proves no controller field slipped past).

### Shared Pattern SP-3 — Stub body preservation
