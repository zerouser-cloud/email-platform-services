## Lessons recorded for future model instances (perpetuated в ADR Iteration 6 + здесь)

1. **Empirical probe BEFORE locking ADR.** 999.18.1 предположил cache-mount target = `/pnpm/store` без verification — оказалось wrong. Probe должен предшествовать locking.
2. **Diff against last working baseline при rewrite infra files.** 999.18.2 W2 rewrite app.Dockerfile под turbo prune НЕ сделал diff с pre-rewrite working version — потерял `COPY tsconfig.base.json`. Procedure: `git show <last-working-commit>:<file>` + diff review = mandatory step.
3. **Cross-check audit recommendations против user meta-principles.** Audit recommended Pattern A (COPY bypass) — costyl per user's framing. Application of meta-principle would have selected Pattern E earlier.
4. **Third workaround in same phase = systemic gap signal.** When фикс fix №3 в одной фазе — STOP, re-eval root decision (D-01 в этом случае).
5. **Layer separation > clever optimizations.** `pnpm prune --prod` is "clever" (one install, prune later) but mixes Layer 1 (host dev/lifecycle) with Layer 3 (prod runtime). pnpm.io two-stage cleanly separates.
