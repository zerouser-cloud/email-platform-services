**Approach:** single bash script с `set -euo pipefail` semantics — НЕ concatenated `;` chains (which mask exit codes per checker W-2 finding). Retry-loop вместо fixed sleep — proportional timeout per flow (60s native, 120s isolated). Per-flow split: native first → curl → stop → isolated → curl → stop. Любой FAIL surfaces explicit reason + non-zero exit.

**Bash script (executed verbatim by `<verify><automated>`):**

```bash
set -euo pipefail
pnpm stop:native >/dev/null 2>&1 || true
pnpm stop:isolated >/dev/null 2>&1 || true

# Native flow — :3000, retry up to 30× × 2s = 60s budget
pnpm start:native &
NATIVE_PID=$!
for i in $(seq 1 30); do
  if curl -fsS http://127.0.0.1:3000/health/ready >/tmp/h-n.json 2>/dev/null; then
    break
  fi
  sleep 2
done
[ -s /tmp/h-n.json ] || { echo "FAIL native: /health/ready не вернул 200 за 60s"; exit 1; }
grep -q '"status":"ok"' /tmp/h-n.json || { echo "FAIL native: status != ok"; exit 1; }
pnpm stop:native

# Isolated flow — :4000, retry up to 60× × 2s = 120s budget (Docker boot longer)
pnpm start:isolated
for i in $(seq 1 60); do
  if curl -fsS http://127.0.0.1:4000/health/ready >/tmp/h-i.json 2>/dev/null; then
    break
  fi
  sleep 2
done
[ -s /tmp/h-i.json ] || { echo "FAIL isolated: /health/ready не вернул 200 за 120s"; exit 1; }
grep -q '"status":"ok"' /tmp/h-i.json || { echo "FAIL isolated: status != ok"; exit 1; }
pnpm stop:isolated

echo "PASS dual-mode smoke"
```

**Verification semantics:**

- `set -euo pipefail` — любой non-zero exit прерывает script + propagates exit code (no masked failures from concatenated `;` chains)
- Retry-loop вместо fixed `sleep 30/60` — boot may be faster или slower; ждём до first 200, fail только если timeout exceeded
- Per-flow timeout proportional к expected boot time: native ~60s, isolated ~120s (Docker images cold-boot)
- Explicit FAIL messages указывают КАКОЙ flow + КАКОЙ aspect (timeout vs status payload)
- Final `echo "PASS dual-mode smoke"` printed только если both flows succeed

**JSON body validation:** `grep -q '"status":"ok"'` ensures NestJS Terminus reports overall green. Полная 6-indicator structure (database, redis, rabbitmq, parser-storage, reports-storage, gateway-grpc-clients все `"up"`) captured в /tmp/h-n.json + /tmp/h-i.json для SUMMARY documentation; per-indicator validation — Self-Check author's responsibility post-execution.

**Failure handling:** If exit non-zero — STOP (script's `set -e` already enforces). Capture full /tmp/h-n.json + /tmp/h-i.json contents для SUMMARY diagnostics. Escalate user. Specifically для isolated flow — это был BLOCKED gate из 999.18.2; FAIL post-Plan-01 = scope mismatch не fully resolved (root-cause investigation required).

**Anti-pattern (per memory `feedback_use_package_scripts`):** NEVER fall back на raw `docker compose -f ...` commands; if `pnpm start:isolated` doesn't bring the stack up properly, that's the bug to fix, not a workflow to bypass.

**Anti-pattern (per checker W-2 closed):** NEVER concatenate commands с `;` — masks exit codes. `set -euo pipefail` + per-flow blocks с explicit `[ -s ... ]` + `grep -q` checks обязательны.
