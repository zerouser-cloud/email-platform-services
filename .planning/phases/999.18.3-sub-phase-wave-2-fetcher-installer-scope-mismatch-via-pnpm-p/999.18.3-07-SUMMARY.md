## Decisions Made

- **Architectural husky elimination, not tool-swap:** FR-01..FR-03 ratified path is "drop entirely" (per CONTEXT.md iter 7). Rationale per planning chain: husky's `prepare` script triggered re-run on `pnpm prune --prod` (pnpm bug #7068), leaking devDeps state into Docker builder layer — root cause of 5 BLOCKED iterations 999.18.3. Tool-swap (husky→lefthook) addresses husky-specific bugs, not class. Empirically MAANG-canonical (React/Astro public repos verified iter 7).

- **Two-install Vercel canonical (FR-04):** prod-deps stage runs `pnpm install --prod --frozen-lockfile` once (no devDeps → no husky achievable); builder stage runs full install + turbo build, no `pnpm prune --prod` (D-01 Variant 2 superseded — eliminates ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY trigger entirely; D-10 `ENV CI=true` fence becomes unnecessary).

- **Distroless runner CMD form (Rule 1 fix):** plan canonical_dockerfile_target prescribed `CMD ["node", "dist/main.js"]` which would have shipped silently broken (`gcr.io/distroless/nodejs22-debian12:nonroot` has ENTRYPOINT `["/nodejs/bin/node"]`, so prepended "node" became a module-name lookup → `MODULE_NOT_FOUND /app/node`). Corrected to canonical distroless form `CMD ["dist/main.js"]`.

- **pnpm-workspace runtime closure (Rule 1 fix):** plan canonical prescribed `COPY --from=prod-deps /app/node_modules ./node_modules` (single tree). Empirically wrong: pnpm splits deps across `/app/node_modules/.pnpm/` (shared store) and `/app/apps/${APP_NAME}/node_modules/` (per-app symlinks). Both must travel together; WORKDIR set to `/app/apps/${APP_NAME}`.

- **/app/proto runtime files (Rule 1 fix):** `.env.docker` declares `PROTO_DIR=/app/proto` (F-05 single-source-of-truth preserved — no `ENV PROTO_DIR` in Dockerfile), but physical proto files must exist at `/app/proto` for grpc-js loader. Pre-P07 Dockerfile silently omitted this COPY — that's why 999.18.2 Wave 2 isolated smoke gate had never PASSed. Added `COPY --from=builder /app/packages/contracts/proto /app/proto`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Builder stage two-step COPY (out/json then out/full)**

- **Found during:** Task 3, first build attempt (gateway)
- **Issue:** Plan canonical `<canonical_dockerfile_target>` prescribed single `COPY --from=pruner /app/out/full/ ./` in builder stage. `turbo prune --docker` emits `pnpm-lock.yaml` ONLY into `out/json/` (manifests-only sub-tree), not `out/full/` (sources sub-tree). Builder stage's `pnpm install --frozen-lockfile` failed with `ERR_PNPM_NO_LOCKFILE`.
- **Fix:** Two-step COPY pattern matching Vercel canonical: `COPY --from=pruner /app/out/json/ ./` first (manifests + lockfile, enables Docker layer cache for install when sources change but manifests don't), `pnpm install --frozen-lockfile`, then `COPY --from=pruner /app/out/full/ ./` (sources).
- **Files modified:** `infra/docker/app.Dockerfile`
- **Verification:** All 6 service images build green; install layer cached when only sources change.
- **Committed in:** `d231706` (Task 3 main commit, fix landed pre-commit)

**2. [Rule 1 — Bug in plan] Distroless CMD form**

- **Found during:** Task 3, isolated mode smoke (first attempt)
- **Issue:** Plan canonical CMD `["node", "dist/main.js"]` causes `MODULE_NOT_FOUND /app/node` runtime crash. Distroless image `gcr.io/distroless/nodejs22-debian12:nonroot` has `ENTRYPOINT ["/nodejs/bin/node"]`; CMD passes ARGS to entrypoint. With "node" as first arg, node tries to import a module named "node" → fails. All 5 service containers crash-loop on startup.
- **Fix:** `CMD ["dist/main.js"]` (no leading "node"). Distroless canonical form per Google distroless docs.
- **Files modified:** `infra/docker/app.Dockerfile`
- **Verification:** Containers start; `node -e "require('reflect-metadata')"` returns true; gateway HTTP /health/ready returns 200.
- **Committed in:** `75b4fb9` (Rule 1 fix commit)

**3. [Rule 1 — Bug in plan] pnpm-workspace runtime closure shape**

- **Found during:** Task 3, isolated mode smoke (second attempt)
- **Issue:** Plan canonical COPY shape prescribed `COPY --from=prod-deps /app/node_modules ./node_modules` (single tree, WORKDIR=/app). Empirically wrong: pnpm 11's `--prod` install creates a HOISTED `.pnpm/` store at workspace root `/app/node_modules/` and PER-APP symlinks at `/app/apps/${APP_NAME}/node_modules/`. The per-app symlinks are what the app actually consumes; root has only the shared store. Plan canonical resulted in `/app/node_modules/` containing only `@email-platform/` workspace symlinks + nothing for runtime deps → `Cannot find module 'reflect-metadata'`.
- **Fix:** Three-COPY runtime closure: (a) `COPY --from=prod-deps /app/node_modules /app/node_modules` (shared .pnpm store + .modules.yaml), (b) `COPY --from=prod-deps /app/apps/${APP_NAME}/node_modules /app/apps/${APP_NAME}/node_modules` (per-app symlinks), (c) `COPY --from=builder /app/packages /app/packages` (compiled dist/). WORKDIR set to `/app/apps/${APP_NAME}` so Node resolution walks per-app tree first then shared store.
- **Files modified:** `infra/docker/app.Dockerfile`
- **Verification:** `docker run --rm gateway:dev -e "console.log(!!require('reflect-metadata'))"` prints `true`.
- **Committed in:** `75b4fb9` (Rule 1 fix commit)

**4. [Rule 1 — Bug in plan] /app/proto runtime files missing**

- **Found during:** Task 3, isolated mode smoke (third attempt)
- **Issue:** `.env.docker` declares `PROTO_DIR=/app/proto` (consumed by `proto-resolver.ts` at runtime to load .proto files for grpc-js loader). Plan canonical Dockerfile (and pre-P07 Dockerfile lineage all the way back to 999.18.2) NEVER copied `packages/contracts/proto/*.proto` to `/app/proto/`. Containers started, dependencies resolved, but `ClientGrpcProxy.loadProto()` failed with `ENOENT: no such file or directory, open '/app/proto/notifier.proto'` and dependent variants for parser/sender/audience/auth — this is exactly why 999.18.2 Wave 2 isolated smoke gate never passed (5 BLOCKED iterations chain). Native mode worked because PROTO_DIR is overridden in `.env` to point to host `packages/contracts/proto/`.
- **Fix:** Added `COPY --from=builder /app/packages/contracts/proto /app/proto` in Stage 2 runner. F-05 single-source-of-truth preserved (no `ENV PROTO_DIR` in Dockerfile — value still lives only in `.env.docker`); only physical files added to image.
- **Files modified:** `infra/docker/app.Dockerfile`
- **Verification:** Isolated mode `pnpm start:isolated` → `/health/ready` returns HTTP 200 with all 6 upstreams up in 20s.
- **Committed in:** `75b4fb9` (Rule 1 fix commit)
