### F-01 (AUTHORITATIVE, nmv): Campaign/recipient lifecycle statuses passed as inline string literals at service call-sites

- **ID:** nmv-F-01
- **Direction:** AUTHORITATIVE
- **Skill:** `no-magic-values`
- **Claim:** `PauseCampaignService`, `ResumeCampaignService`, `MarkAsSentService`, and `ResetSendStatusService` pass lifecycle status values (`'paused'`, `'active'`, `'sent'`, `'pending'`) as **inline string literals** to `TransitionCampaignStatusUseCase.execute()` / `TransitionRecipientsStatusUseCase.execute()`. While a `CampaignLifecycleStatus = 'paused' | 'active'` type alias exists (ALLOWED for type annotations), the skill's decision tree explicitly routes "set of related string values (status codes, tiers, types)" to the `as const` object with UPPER_SNAKE_CASE keys pattern (`.agents/skills/no-magic-values/SKILL.md` lines 72-73). At the call site `execute(cmd.id, 'active')`, `'active'` is a **behavioural identifier value**, not a type annotation — it should be `CAMPAIGN_LIFECYCLE_STATUS.ACTIVE` (or similar). Same pattern at 4 call sites (`'paused'`, `'active'`, `'sent'`, `'pending'`) plus 2 discriminator literals (`'by-ids'`, `'by-group'`).
- **Evidence:**

- **Phase-decision xref:** N/A (AUTHORITATIVE — universal rule, no phase-decision context required)
- **Recommended remediation:** fix-code — extract `CAMPAIGN_LIFECYCLE_STATUS = { ACTIVE: 'active', PAUSED: 'paused' } as const` in `apps/sender/src/application/use-cases/transition-campaign-status.use-case.ts` (or a neighbouring `*-constants.ts`) and `RECIPIENT_LIFECYCLE_STATUS = { SENT: 'sent', PENDING: 'pending' } as const` + `RECIPIENT_SELECTOR_KIND = { BY_IDS: 'by-ids', BY_GROUP: 'by-group' } as const` in the audience counterpart; replace all 6 inline call-site occurrences with the named constants (preserves the `type` aliases unchanged via `typeof`).
- **Severity:** minor — narrow blast radius (4 files), no runtime defect today, but the pattern will multiply as the business-logic phase adds more transition services; remediating now prevents cascade.

### F-02 (AUTHORITATIVE, nmv): `RetryOptions` / `RETRY_DEFAULTS` uses lower-case interface-style field names instead of UPPER_SNAKE_CASE per skill Pattern 1

- **ID:** nmv-F-02
- **Direction:** AUTHORITATIVE
- **Skill:** `no-magic-values`
- **Claim:** `packages/foundation/src/external/resilience/retry-connect.ts` exports `RETRY_DEFAULTS` bound to an interface `RetryOptions` with fields `maxRetries`, `baseDelayMs`, `maxDelayMs`. The skill's Pattern 1 (lines 83-100 of SKILL.md) explicitly locks **UPPER_SNAKE_CASE keys** for `as const` constant objects (`MAX_CONNECTIONS`, `IDLE_TIMEOUT_MS`, `CONNECTION_TIMEOUT_MS`). Neighbouring constants files follow the convention (`PG_POOL_DEFAULTS.MAX_CONNECTIONS` in `packages/foundation/src/external/persistence/persistence.constants.ts`, `REDIS_DEFAULTS.KEEP_ALIVE_MS` in `cache.constants.ts`, `RETRY_DEFAULTS.RETRY_MAX_ATTEMPTS` in the *other* `retry/constants.ts`). The legacy `retry-connect.ts` is the lone deviation — and it also co-locates the constant with the function instead of relocating to a `resilience.constants.ts` file per the skill's "Pattern 1 + extract to `*-constants.ts`" decision path (lines 60-67, 82-83).
- **Evidence:**

  ```bash
  $ sed -n '1,12p' packages/foundation/src/external/resilience/retry-connect.ts
  export interface RetryOptions {
    maxRetries: number;

  export const RETRY_DEFAULTS: RetryOptions = {

  $ sed -n '8,17p' packages/foundation/src/external/persistence/persistence.constants.ts

  $ sed -n '10,14p' packages/foundation/src/external/cache/cache.constants.ts

    MAX_RETRIES_PER_REQUEST: 3,
  } as const;

  $ sed -n '12,17p' packages/foundation/src/external/http/retry/constants.ts
  export const RETRY_DEFAULTS = {
    RETRY_MAX_ATTEMPTS: 3,
    RETRY_BACKOFF_MIN_MS: 200,
    RETRY_BACKOFF_MAX_MS: 5_000,
    RETRY_JITTER_RATIO: 0.5,
  } as const;
  ```

- **Phase-decision xref:** N/A (AUTHORITATIVE — universal rule)
- **Recommended remediation:** fix-code — relocate the default triple to a new `packages/foundation/src/external/resilience/resilience.constants.ts` as `RETRY_CONNECT_DEFAULTS = { MAX_RETRIES: 5, BASE_DELAY_MS: 200, MAX_DELAY_MS: 5_000 } as const`; keep `RetryOptions` interface (lower-case fields are correct for a general options **type**) but have `retryConnect()` spread a mapper from constants to interface shape (`{ maxRetries: RETRY_CONNECT_DEFAULTS.MAX_RETRIES, ...}`). Alternative: rename the interface fields to UPPER_SNAKE_CASE (breaks interface convention — not recommended). Solution ranking in Plan 04.
- **Severity:** minor — style/convention drift, no behavioural defect; visible in grep for "foundation defaults" audits and produces a false positive for future `no-magic-values` sweeps if convention diverges further.
- **Solution ref:** → SOLUTIONS.md nmv-F-02 (Plan 04)
