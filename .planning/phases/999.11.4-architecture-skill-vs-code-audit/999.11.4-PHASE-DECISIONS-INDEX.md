## Methodology

- **Discovery grep templates:** see Plan 00 Task 1 (PATTERNS.md §"Pattern Assignments").
- **Extraction regex:** `^- \*\*(D-\d+[a-z]?)[:.]?\*\*\s*(.*)$` — matches the bullet-bold decision pattern used consistently across all phases.
- **Topic-area inference rule (locked):** keyword-based classification. Each decision summary + its parent section header is tested against 14 topic regexes in priority order. First match wins (lowest priority number first). Unmatched decisions bucket into `uncategorized` and become candidates for D-06 orphan/needs-new-skill output.
- **Orphan rule:** a decision is orphan if its topic_area maps to an existing skill (per topic→skill table) BUT the D-XX ID does not appear in that skill's SKILL.md or references/*.md body.
- **Severity heuristic (orphan section):** `high` if decision is in last 5 phases (999.10+) AND topic-area has existing skill → likely active drift. `medium` if decision in any phase + topic-area has existing skill → skill stale. `low` if `uncategorized` OR decision in deprecated phase → may be legitimately retired.
