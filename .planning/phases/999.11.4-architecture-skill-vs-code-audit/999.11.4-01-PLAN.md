For `no-magic-values` (sub-agent 1):
```
- Hard-coded numeric literals not in constants:    grep -rnE '\b(?<!const\s)\b[0-9]{2,}\b' apps/ --include='*.ts' (refine to exclude legal 0/1/-1 idioms, type literals, port numbers in comments)
- Hard-coded strings used as DI tokens (should be Symbol):    grep -rnE 'inject\(\s*["'\''][A-Z_]+["'\'']\s*\)' apps/ packages/ --include='*.ts'
- Hard-coded URLs/paths (should be in env/config):    grep -rnE 'http://|https://|/api/' apps/ packages/ --include='*.ts'
- Magic value lists in code (should be in *-constants.ts as `as const` object):    grep -rn -B 1 -A 5 'as const' apps/ packages/ --include='*.ts' | head -50 (sanity check that constants ARE in *-constants.ts files)
- Cross-check: which apps/packages files have magic numbers but no `*-constants.ts` sibling?    find apps packages -name '*.ts' -path '*/src/*' | xargs grep -lE '\b[0-9]{3,}\b' | head -20
```

```

```
