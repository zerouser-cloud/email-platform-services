**Variant generation guidance per remediation type from AUDIT finding:**

- For finding with `Recommended remediation: refresh-skill`:
  - V1 (recommended): refresh skill text in specific way (cite the D-XX or new pattern that should be added)
  - V2 (alternative): leave skill as-is + add deprecation note (lighter touch)
  - V3 (rare alternative): rewrite section from scratch (heavier)

- For finding with `Recommended remediation: fix-code`:
  - V1 (recommended): apply specific code change (cite the file + new pattern)
  - V2 (alternative): refactor differently (alternative pattern)
  - V3 (rare): leave code + add ad-hoc-drift sanctioned exception in skill

- For finding with `Recommended remediation: leave-as-is`:
  - V1 (recommended): leave + document rationale in skill (note why not a violation)
  - V2 (alternative): defer to later phase (if context for "later" exists)
