## Runtime Behavioral Invariants (MUST PASS)

24.1 is a pure refactor — behavior must remain identical to Phase 24 baseline. After `pnpm start:isolated`:

```bash
# Baseline state (CB closed, 0 consecutive failures)
curl -s http://localhost:4000/test/http-client/state
# Expect: { "cb": "closed", "consecutiveFailures": 0 }

# Happy path
curl -s -X POST http://localhost:4000/test/http-client/probe
# Expect: outcome.ok === true, after.cb === "closed"

# Force CB to open
curl -s -X POST 'http://localhost:4000/test/http-client/burst-fail?count=5&timeoutMs=1'
# Expect: 5 failed results, finalState.cb === "opened"

# Fast-fail in open state
curl -s -X POST http://localhost:4000/test/http-client/probe
# Expect: outcome.ok === false, error contains "Circuit open for HttpSmokeClient"

# 5xx retried (3 attempts)
time curl -s -X POST 'http://localhost:4000/test/http-client/status?code=500'
# Expect: ~1.5-7s total (3 attempts + jitter backoff)

# 4xx NOT retried (1 attempt)
time curl -s -X POST 'http://localhost:4000/test/http-client/status?code=404'
# Expect: < 1s total (single attempt)
```

## Token Rotation Commit Order (D-29 / D-30)

**Operator-driven sequence** — must complete steps 1-6 BEFORE any git commit in this phase:

1. @BotFather revokes current token, issues new one
2. Paste new token into Coolify Production env → save
3. Paste new token into Coolify Dev env → save
4. Update local `.env.docker` with new value
5. Coolify redeploys notifier; check logs for no 401 Unauthorized
6. Old token is invalid — historical git commits pose no active threat

**Then:** `git rm --cached .env.docker` + create `.env.docker.example` happen in same or subsequent commit.
