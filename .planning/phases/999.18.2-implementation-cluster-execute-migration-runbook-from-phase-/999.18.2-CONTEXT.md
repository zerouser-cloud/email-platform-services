### Architectural Decisions (locked in 999.18.1-ADR-001)

- **Decision (a)** — DROP `pnpm deploy --prod` from Stage 2; replace с manual COPY closure (`COPY --from=builder /app/apps/${APP_NAME}/dist + /app/apps/${APP_NAME}/node_modules + /app/packages`). F-15 archaeology root-cause closure.
- **Decision (b) M3** — DROP `injectWorkspacePackages: true` from `pnpm-workspace.yaml` entirely (architectural-eliminate, NOT M1 perpetuate-with-mit). Stage 1 uses fetcher sub-stage: `pnpm fetch --prod` (downloads to virtual store) + `pnpm install --offline` (resolves from store). F-01 / F-02 closure.
- **Decision (c) Distroless** — Stage 2 runner = `gcr.io/distroless/nodejs22-debian12:nonroot` (NOT `node:22-alpine`). User=`65532:65532` built into image. No shell, no apk, no addgroup/adduser. F-20 image-determinism closure.
- **Decision (c.1)** — Gateway healthcheck = HTTP `/health/ready` via wget (gateway сохраняет HTTP server для REST API). Compose `["CMD", "wget", "-qO-", "http://localhost:3000/health/ready"]`.
- **Decision (c.2)** — auth/sender/parser/audience healthcheck = `grpc.health.v1.Health` protocol via `grpc_health_probe` binary. Drop HTTP server в этих 4 сервисах. Compose `["CMD", "grpc_health_probe", "-addr=:<grpc-port>"]`. F-04 / F-04-d8 transport-aligned closure.
- **Decision (c.3)** — notifier = gRPC Health-only server (notifier не имел HTTP изначально + не имеет business-logic gRPC; только Health protocol). Compose `["CMD", "grpc_health_probe", "-addr=:<notifier-grpc-port>"]`.
- **Decision (d) Placement A** — `pnpm generate:contracts` lives в pre-build CI step (`.github/workflows/docker-build.yml`) BEFORE matrix `docker buildx build`. Drift-check gate: `git diff --exit-code packages/contracts/src/generated/` exits 0 OR fails CI. F-12 V2 closure.
- **Implicit-fifth Multi-arch** — `docker/build-push-action@v5` `platforms: linux/amd64,linux/arm64` + `docker/setup-qemu-action@v3` setup BEFORE buildx. QEMU emulation initial; native ARM runners migration owned by DevOps (T-CI-01 trigger). F-08 closure.
