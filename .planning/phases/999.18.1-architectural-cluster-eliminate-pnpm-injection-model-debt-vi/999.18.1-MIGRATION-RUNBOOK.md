Если F-03 fix landed first — F-01 / F-02 staleness exposes across all 6 services simultaneously (pnpm sync hook `syncInjectedDepsAfterScripts: [build]` would still be active).
- **Wave 2 → Wave 3** — Dockerfile MUST be byte-deterministic before multi-arch CI rollout per F-20. Multi-arch builds (`docker buildx build --platform linux/amd64,linux/arm64`) compound non-determinism if Dockerfile has any non-deterministic surface (cache-mount races, install-step variability) — first failing arch reproduces digest mismatch на second build of same git SHA.

**Rollback anchor:** every wave commit MUST be `git revert`-able as a single atomic commit per CLAUDE.md "Atomic commits" + memory `feedback_phase_completeness`. Wave 2 — самая invasive — обязательно проходит rollback drill (revert + dual-mode smoke на reverted state) BEFORE Wave 3 starts.
