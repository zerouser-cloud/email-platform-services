## Area 1: Granularity rule (principle vs inventory)

### Q1 — Какой heuristic лучше всего отделяет 'principle' от 'inventory'?

| Option | Description | Selected |
|--------|-------------|----------|
| Rename test | Если утверждение скилла ломается при rename файла/класса/variable — inventory; выживает — principle. Объективно верифицируемо. | ✓ |
| Count test | Если в скилле есть конкретное число — inventory. Просто, но грубо — правила вроде "единственный legal process.env read-site" звучат как principle, но содержат '1'. | |
| Descriptive vs prescriptive | Prescriptive = principle; descriptive = inventory. Требует интерпретации. | |
| Hybrid (Rename + Count) | Оба теста — если хотя бы один fails → inventory. Более строго, ловит краевые случаи. | |

**User's choice:** Rename test
**Notes:** Принято как D-1 — authoritative heuristic для всей фазы.
