## Decisions Made

- **D-08 A2 pattern realised mechanically**: `Symbol()` token + useValue provider + providers[] entry — chose Plan option A (append Symbol below existing port Symbols, above `as const` pagination blocks) for all 5 existing files; created gateway.constants.ts fresh per PT-12 with a file-level comment documenting the Phase/decision provenance.
- **useValue > useFactory**: `loadConfig()` in `packages/config/src/config-loader.ts` caches by schema reference (WeakMap-style Map), so eager call at module-definition time is safe and produces the same cached value every subsequent consumer receives. Provider is a single compile-time constant — no DI-ordering surprises. Matches CONTEXT.md D-08 explicit shape.
- **Provider position in providers[]**: Inserted FIRST (before port bindings) so reviewers see the composition-root concern at the top of the array. Matches plan action text "place it FIRST so it's visually anchored as a composition-root concern."
- **AppConfigModule kept live (dual-path)**: Critical for Commits 2-8 to migrate callsites one-at-a-time without breaking intermediate runtime state. D-11 full removal deferred to Commit 9 (`999.11.1-09-remove-nestjs-config-dep`).
- **`as {Svc}Env` cast retained**: The cast is a Phase 999.1 (TopologySchema static refactor) concern, not this phase. Documented in each provider file's JSDoc.
