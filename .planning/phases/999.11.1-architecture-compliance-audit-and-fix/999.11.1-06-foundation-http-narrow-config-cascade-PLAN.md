<objective>
**Commit 6 of 10** — `refactor(999.11.1-06): foundation HTTP narrow config + cascade 3 vendor modules`

Migrate `packages/foundation/src/external/http/provider/http-client.provider.ts` away from `inject: [ConfigService, ClsService]` to a generic typed-env pattern. The `build(deps)` callback contract changes from receiving `{ ...deps, config: ConfigService }` to `{ ...deps, env: TEnv }` where `TEnv` is the app's narrow vendor env slice. Cascade through 3 vendor modules (Telegram in notifier, AppStoreSpy in parser, Cloud Functions in sender).

Addresses: **D-10** (foundation HTTP narrow config), **D-12** callsites IC-06 (foundation) + IC-10/IC-11/IC-12 (3 vendor modules), **PT-04** (as XxxEnv casts stay in main.ts — not touched).

**Design decision:** Keep the existing `baseUrlEnvKey` vs `baseUrlLiteral` OR pattern (already designed for smoke/test clients). Swap the internal `config.getOrThrow<string>(opts.baseUrlEnvKey)` read to `env[opts.baseUrlEnvKey]` where `env` is a generic `Record<string, string>`-shaped param. The generic approach preserves all Phase 24.1 design decisions (D-18 getOrThrow reliability — now replaced by Zod-validated `{Svc}Env` guarantees stricter at compile time).

**Shape contract:** The factory takes `opts.envToken: symbol` (new). `inject: [envToken, ClsService]`. useFactory `(env, cls)` — `env` is typed by generic but consumed via index access for `baseUrlEnvKey` lookup. The `build(deps + env)` callback receives the narrow env slice (e.g. `NotifierEnv` subset carrying `TELEGRAM_BASE_URL` + `TELEGRAM_BOT_TOKEN`).
</objective>

export interface HttpClientProviderOpts {
  readonly token: symbol;
  readonly logContext: string;
  readonly envToken: symbol;      // NEW — DI token for the app's {SVC}_CONFIG
  readonly baseUrlEnvKey?: string;
  readonly baseUrlLiteral?: string;
  readonly timeoutMs?: number;
  readonly cb?: Partial<CbOptions>;
}

export function httpClientProvider<T extends AbstractHttpClient, TEnv extends Record<string, unknown>>(
  opts: HttpClientProviderOpts,
  build: (deps: HttpClientDeps & { env: TEnv }) => T,
): Provider {
  return {
    provide: opts.token,
    inject: [opts.envToken, ClsService],
    useFactory: (env: TEnv, cls: ClsService): T => {
      ...
      const baseUrl = opts.baseUrlLiteral ?? (env[opts.baseUrlEnvKey as string] as string);
      ...
      return build({ ...deps, env });
    },
  };
}
