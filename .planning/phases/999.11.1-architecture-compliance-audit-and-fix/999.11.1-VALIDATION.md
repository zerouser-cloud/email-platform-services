## Phase Gate — D-15 Dual-Mode Smoke Recipe

Run AFTER the final commit (no amendment). Follows `runtime-smoke-verification` SKILL.md.

```bash
# Pre-flight — clean slate
pnpm stop:native
pnpm stop:isolated

# Native mode
pnpm start:native
sleep 30
curl -s -o /tmp/999.11.1-native-ready.json -w "%{http_code}" http://localhost:3000/health/ready
jq '.status == "ok" and (.info | to_entries | all(.value.status == "up"))' /tmp/999.11.1-native-ready.json
# Expect: HTTP 200, body .status == "ok", 5/5 upstreams up
pnpm stop:native

# Isolated mode
pnpm start:isolated
sleep 60
curl -s -o /tmp/999.11.1-isolated-ready.json -w "%{http_code}" http://localhost:4000/health/ready
jq '.status == "ok" and (.info | to_entries | all(.value.status == "up"))' /tmp/999.11.1-isolated-ready.json
# Expect: HTTP 200, same body shape

# Container log scan — zero error/warn across 6 containers in last 2 min
for svc in gateway auth sender parser audience notifier; do
  docker logs --since 2m infra-$svc-1 2>&1 | grep -E '"level":"(error|warn)"' | head -3
done

pnpm stop:isolated
```

**Evidence to persist:** Save `/tmp/999.11.1-native-ready.json` + `/tmp/999.11.1-isolated-ready.json` excerpts into the final SUMMARY.md.
