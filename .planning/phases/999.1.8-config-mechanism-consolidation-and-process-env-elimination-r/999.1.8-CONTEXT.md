### createConfigModule API shape (from Q3)

- **D-08: Factory function returns DynamicModule.** Signature:
  ```typescript
  export interface CreateConfigModuleOptions<TEnv> {
    schema: z.ZodType<TEnv>;
    token: symbol;
    narrowPorts?: Array<{ port: symbol; slice: (env: TEnv) => unknown }>;
  }
  
  export function createConfigModule<TEnv>(
    opts: CreateConfigModuleOptions<TEnv>
  ): DynamicModule;
  ```
- **D-09: Returned DynamicModule внутри имеет `@Global()` scope.** Preserves 999.11.1 Plan 10 Rule 3 fix: narrow port providers visible to nested `forRootAsync({inject: [...]})` dynamic modules (LoggingModule, ClientsModule, etc.).
- **D-10: App-side shape:**
  ```typescript
  // apps/audience/src/infrastructure/bootstrap/config/audience-config.module.ts
  import { createConfigModule } from '@email-platform/foundation';
  import { PERSISTENCE_CONFIG_PORT, LOGGING_CONFIG_PORT, GRPC_CLIENT_CONFIG_PORT } from '@email-platform/foundation';
  import { AudienceEnvSchema } from './audience-env.schema';
  import { AUDIENCE_CONFIG } from './audience-config.constants';
  
  export const AudienceConfigModule = createConfigModule({
    schema: AudienceEnvSchema,
    token: AUDIENCE_CONFIG,
    narrowPorts: [
      { port: PERSISTENCE_CONFIG_PORT, slice: (c) => ({ DATABASE_URL: c.DATABASE_URL }) },
      { port: LOGGING_CONFIG_PORT, slice: (c) => ({ LOG_LEVEL: c.LOG_LEVEL, LOG_FORMAT: c.LOG_FORMAT }) },
      { port: GRPC_CLIENT_CONFIG_PORT, slice: (c) => ({ PROTO_DIR: c.PROTO_DIR, GRPC_DEADLINE_MS: c.GRPC_DEADLINE_MS, grpcUrls: { PARSER_GRPC_URL: c.PARSER_GRPC_URL } }) },
    ],
  });
  ```
  ~15 LOC per service vs current ~60 LOC. Eliminates `@Module({})` + `forRoot()` static + `@Global()` decoration boilerplate — factory incapsулирует.
- **D-11: Consumer import pattern change:** `apps/{svc}.module.ts` импортирует `AudienceConfigModule` напрямую (constant, not class) — **NO `.forRoot()` call**. Breaking change vs current; mechanical update во всех 6× `{svc}.module.ts`.
- **D-12: {svc}-config.provider.ts deprecated.** Factory incapsулирует useFactory провайдер, отдельного файла не требуется. Plan 06 delete'ит 6× `*-config.provider.ts`.

### Narrow port slice declarations (from Q4)

- **D-13: Inline narrowPorts в apps.** Каждый сервис сам перечисляет `narrowPorts: [...]` в own bootstrap/config/*-config.module.ts. Per-service variance preserved (gateway имеет 5 grpcUrls, sender 1, parser 1, audience 1, notifier+auth нет grpc consumers). Rationale: tuple sliсe factories короче чем foundation pre-declared slice API, и не требуют future updates когда новый сервис появляется с нестандартными полями.
