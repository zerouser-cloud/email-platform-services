<objective>
Migrate ALL `loadConfig` consumers from `@email-platform/config` to `@email-platform/foundation`, then delete `packages/config/src/config-loader.ts` and its re-export line. This is the consumer-first D-04 switchover commit: one atomic operation that updates every import site AND removes the old source, so no intermediate state has a broken build.

Plan scope (F-15 resolution + F-16 partial):
- 4× `apps/{auth,audience,parser,sender}/drizzle.config.ts` — switch `DatabaseSchema.parse(process.env)` → `loadConfig(DatabaseSchema)`; add `SERVICE.{svc}.id` in `schemaFilter` (dual-import per Three-Layer Rule: schema from config, loader from foundation).
- 6× `apps/*/src/main.ts` — switch `loadConfig` import from `@email-platform/config` to `@email-platform/foundation`. 5 services currently dual-import `SERVICE, loadConfig` from config (split into 2 imports); 1 (gateway) currently imports only `loadConfig` (rewritten to foundation).
- Delete `packages/config/src/config-loader.ts` (20 LOC).
- Remove L6 `export * from './config-loader';` from `packages/config/src/index.ts`.

Purpose:
- Close F-15: eliminate 4 direct `process.env` read-sites in CLI configs.
- Close the import-path portion of F-16: `loadConfig` is now exclusively owned by foundation (Mechanism tier). Plan 05 handles the remaining app-side boilerplate → factory migration.
- Establish I-0.1 compliance globally: `grep -rn 'process\.env' apps/` = 0, `grep -rn 'process\.env' packages/` = 1 (foundation only).

Output:
- 12 modified files (4 drizzle + 6 main + 1 config barrel + 1 deletion).
- 1 atomic commit: `refactor(999.1.8-04): migrate loadConfig consumers to @email-platform/foundation + delete packages/config/src/config-loader.ts`.

**Why this is one atomic commit, not 2-3:** If we split «migrate consumers» from «delete source», then intermediate states compile but violate F-16 architectural intent (two entry points for loadConfig — one in each package). If we split per-service, main.ts changes and drizzle.config.ts changes belong together for each service. The cleanest atomic unit is «everyone switches + old source goes away».
</objective>
