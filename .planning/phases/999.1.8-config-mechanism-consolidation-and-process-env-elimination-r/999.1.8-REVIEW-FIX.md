### WR-02: Приведение `as AuthEnv` / `as AudienceEnv` / etc. в каждом `main.ts`

**Files modified:**
- `packages/foundation/src/external/config/load-config.ts`
- `apps/auth/src/main.ts`
- `apps/audience/src/main.ts`
- `apps/gateway/src/main.ts`
- `apps/notifier/src/main.ts`
- `apps/parser/src/main.ts`
- `apps/sender/src/main.ts`

**Commit:** `aa4f988`

**Applied fix:** вариант 2 из REVIEW.md (generic parameter).

Причина выбора варианта 2 (а не варианта 1 с `z.infer`): pre-fix grep по коду — не planning-docs — показал четыре внешних consumer-а интерсекшн-алиасов:

- `apps/notifier/src/infrastructure/outbound/http-clients/telegram/telegram.module.ts` — `httpClientProvider<TelegramClient, NotifierEnv>(...)`
- `apps/sender/src/infrastructure/outbound/http-clients/cloud-functions/cloudfn.module.ts` — `httpClientProvider<CloudFnClient, SenderEnv>(...)`
- `apps/parser/src/infrastructure/outbound/http-clients/appstorespy/appstorespy.module.ts` — `httpClientProvider<AppStoreSpyClient, ParserEnv>(...)`
- `apps/gateway/src/infrastructure/bootstrap/throttle/throttle.module.ts` — `useFactory: (config: GatewayEnv) => ...`

Эти consumer-ы используют именованный intersection-alias как стабильный контракт; переход на голый `z.infer` потребовал бы synchronized замены во всех четырёх файлах и лишил бы архитектурный контракт именованной формы. Поэтому применён вариант 2.

Конкретные изменения:
- `loadConfig<T extends z.ZodType, TEnv = z.infer<T>>(schema: T): TEnv` — добавлен второй generic `TEnv` со значением по умолчанию `z.infer<T>`. Сигнатура симметрична уже существующему `createConfigModule<TSchema, TEnv>` в `create-config-module.ts`.
- JSDoc функции обновлён: описание `@typeParam T` / `@typeParam TEnv`, пример вызова, причина существования параметра (intersection-alias drift).
- 6 call-site-ов в `apps/*/src/main.ts`: `loadConfig(Schema) as AuthEnv` → `loadConfig<typeof Schema, AuthEnv>(Schema)`. Приведение `as` устранено; рассинхрон между `XxxEnvSchema` и `XxxEnv` теперь compile-time ошибка.
- Внешние consumer-ы (telegram/cloudfn/appstorespy/throttle) не трогаются — тип `NotifierEnv`/`SenderEnv`/`ParserEnv`/`GatewayEnv` остаётся именованным intersection-alias, как и было.

Baseline lint + build зелёные после каждого фикса (проверено между коммитами).
