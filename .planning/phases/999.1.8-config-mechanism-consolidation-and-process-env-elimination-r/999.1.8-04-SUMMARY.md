## Deviations from Plan

### Rule 3 (Blocking Issue) — Expanded commit scope

**1. [Rule 3 - Blocking] 6× provider files required migration in same commit**

- **Found during:** Task 3 grep sanity check (`grep -rn "loadConfig.*from '@email-platform/config'" packages/ apps/`)
- **Issue:** Plan enumerated 12 files (4 drizzle + 6 main.ts + 2 config source) but missed `apps/*/src/infrastructure/bootstrap/config/*-config.provider.ts` (6 files). These DI provider files import `loadConfig` from `@email-platform/config`. Without migrating them in the same commit as the `config-loader.ts` deletion, TypeScript build fails (`Module '"@email-platform/config"' has no exported member 'loadConfig'`).
- **Fix:** Migrated all 6 provider files to `loadConfig` from `@email-platform/foundation`. Also updated stale doc comments that referenced the old loader path (`packages/config/src/config-loader.ts` → `packages/foundation/src/external/config/load-config.ts`).
- **Files modified (in addition to plan):** 6× `apps/{auth,audience,parser,sender,notifier,gateway}/src/infrastructure/bootstrap/config/*-config.provider.ts`
- **Rationale for same-commit inclusion:** The plan objective is "consumer-first atomic switchover — no intermediate broken-build state". Splitting the provider migration into a separate commit would violate this explicit invariant.
- **Commit:** `8cba247` (atomic commit expanded to 18 files)

### Rule 1 (Bug Fix) — Gateway main.ts prettier-induced multi-line import

**2. [Rule 1 - Style Bug] Gateway main.ts lint failure after initial edit**

- **Found during:** Task 4 Step 1 (`pnpm lint` pre-commit gate)
- **Issue:** Merging `loadConfig` into the existing `@email-platform/foundation` import line exceeded prettier's 100-char limit: `import { loadConfig, GrpcToHttpExceptionFilter, SERVER, CORS, BOOTSTRAP } from '@email-platform/foundation';`
- **Fix:** Ran `pnpm eslint src/ --ext .ts --fix` in apps/gateway/, which auto-split the import to multi-line form. Functional equivalence preserved.
- **Files modified:** `apps/gateway/src/main.ts` (formatting only)
- **Commit:** Included in atomic commit `8cba247`
