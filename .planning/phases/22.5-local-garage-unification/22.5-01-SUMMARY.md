# Phase 22.5 Plan 01: Infra Swap (MinIO → Garage) Summary

**One-liner:** Replaced MinIO with Garage v2.1.0 across both local compose stacks (infra-only + isolated), committed the canonical `garage.toml` config, shipped an idempotent `pnpm garage:bootstrap` helper that provisions `parser` + `public` buckets with a static test key, added the `khairul169/garage-webui` sidecar at port 3909, and updated `.env.docker` / `.env.example` to Garage native port 3900 and locked D-11 credentials — without touching app-level code or the storage Zod schema.

## What Shipped

### Task 1 — Config + bootstrap artifacts (commit `1427558`)

- **`infra/docker/garage.toml`** (21 lines): Minimal single-node config. `replication_factor=1`, `sqlite` metadata engine, `[s3_api]:3900` + `[admin]:3903` bind addresses, static `rpc_secret`. No `[s3_web]` section (Q2 — Phase 22.4 will add it for public bucket web hosting). No `admin_token` in TOML — Garage reads the `GARAGE_ADMIN_TOKEN` env var, which is also passed to the WebUI sidecar so both sides agree (Pitfall 7).
- **`infra/docker/garage-bootstrap.sh`** (97 lines, `chmod +x`, `bash -n` clean): Idempotent via marker file `/var/lib/garage/meta/.bootstrapped`. Loads `STORAGE_ACCESS_KEY/SECRET_KEY` from `.env.docker` via `grep + cut` (no `source` pollution). Auto-discovers running Garage container across both compose stacks (falls back from infra-only to isolated). Waits up to ~30 s for `/garage status` to turn green, then runs the 7 verified CLI commands in order: `node id -q`, `layout assign -z local -c 1G <NODE_ID>`, `layout apply --version 1`, `key import --yes` (Pitfall 1 — flag mandatory), `bucket create parser`, `bucket create public`, `bucket allow --key email-platform-local --read --write --owner` for both buckets. Writes marker on success.

### Task 2 — Compose files (commit `b640abb`)

- **`infra/docker-compose.infra.yml`**: Removed `minio` service (lines 44–59) and `minio_data` volume. Added `garage` service using `dxflrs/garage:v2.1.0` with bind-mount of `./docker/garage.toml:/etc/garage.toml:ro`, named volumes `garage_meta` + `garage_data`, `GARAGE_ADMIN_TOKEN` env passthrough, and minimal-image-safe healthcheck `["CMD", "/garage", "-c", "/etc/garage.toml", "status"]`. Added `garage-webui` sidecar using `khairul169/garage-webui:1.1.0` with `API_BASE_URL=http://garage:3903`, `S3_ENDPOINT_URL=http://garage:3900`, `API_ADMIN_KEY=${GARAGE_ADMIN_TOKEN}`, `S3_REGION=garage`, gated on `garage: service_healthy`.
- **`infra/docker-compose.yml`**: Swapped `minio: service_healthy` → `garage: service_healthy` in both `parser` (line 92) and `notifier` (line 138) `depends_on` blocks. No other services touched.
- **`infra/docker-compose.dev-ports.yml`**: `minio: ["9000:9000"]` → `garage: ["3900:3900"]`. Preserved `5432/6379/5672` standard-port publishers.
- **`infra/docker-compose.webui-ports.yml`**: `minio: ["9001:9001"]` → `garage-webui: ["3909:3909"]`. Preserved `15672` (RabbitMQ Management UI). Comment updated to mention Garage WebUI.

Both compose stacks validated via `docker compose -f … config --quiet` (exit 0; only the expected "`GARAGE_ADMIN_TOKEN` variable is not set" warning, which clears when the operator runs `pnpm infra:up` because `.env.docker` is loaded as an `env_file`).

### Task 3 — Env files + npm script (commit `b4545bb`)

- **`.env.docker`**: `STORAGE_ENDPOINT=garage`, `STORAGE_PORT=3900`, `STORAGE_REGION=garage`, `STORAGE_ACCESS_KEY=GKTESTLOCAL0123456789ab`, `STORAGE_SECRET_KEY=<64 zeros>`, `GARAGE_ADMIN_TOKEN=local-dev-admin-token-static-value-for-local-only`. `STORAGE_BUCKET` line removed (D-27 — legacy, never referenced by the storage schema).
- **`.env.example`**: Same Garage values but `STORAGE_ENDPOINT=localhost` (native mode — services on the host reach Garage through the published `3900` port). Comment updated from "minio" to "garage" hostname hint.
- **`package.json`**: Added `"garage:bootstrap": "bash infra/docker/garage-bootstrap.sh"` between `infra:down` and `docker:up`. JSON remained valid (`node -e "JSON.parse(…)"` exit 0).

All other env vars (DATABASE_URL, REDIS_URL, RABBITMQ_URL, port numbers) untouched per the infrastructure-guard skill.
