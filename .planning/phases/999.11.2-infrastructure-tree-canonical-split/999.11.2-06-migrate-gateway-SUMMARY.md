## Decisions Made

See frontmatter `key-decisions`. Most notable:

1. **D-GATEWAY-01** — Gateway `HealthModule` imports `TerminusModule + GrpcClientsModule` (not `PersistenceModule`). Gateway is a pure REST facade with zero database access; `health.controller.ts` injects only 5 `*_GRPC_HEALTH` tokens, never `DATABASE_HEALTH`. This deliberately diverges from auth/sender/parser/audience Plans 01-04 which include foundation's `PersistenceModule.forRootAsync()` in their HealthModule.

2. **D-GATEWAY-02** — Gateway has NO `infrastructure/inbound/` directory. Rationale: REST facade exposes only `HealthController` (moved to `bootstrap/health/` per D-08), no proto-service controllers (no `inbound/grpc/`), no non-health REST endpoint groups yet (those are future feature phases per CONTEXT deferred list — `auth-login-gateway`, `campaigns-api-gateway`, etc.). Creating an empty `inbound/` placeholder would be scope creep and a dead-code smell. D-01 3-bin split is logically complete with 2 bins (bootstrap/ + outbound/) for this service type.

3. **Task ordering** — Per checker Nit 1, Task 2 (client moves) preceded Task 3 (controller move + import rewrite). Since the entire plan lands as one atomic commit and lint only runs at Task 5 gate, the practical intermediate-state lint failure wouldn't manifest — but the discipline yields a bisect-friendly sequence and matches the pattern any future multi-upstream consumer migration should follow.

4. **Pitfall 9 barrel consolidation** — 5→1 import statement reduction in health.controller.ts by preferring the composer-level barrel `from '../../outbound/grpc-clients'` over 5 individual sub-barrel imports. Token count at consumer unchanged (still 5 `*_GRPC_HEALTH` names destructured); import statement count drops to 1.

5. **D-11a vs D-11** — Gateway is the UNIQUE service where D-11a fires: its `gateway.constants.ts` contained ONLY `GATEWAY_CONFIG` Symbol (added in 999.11.1-01 for parity), so D-10's relocation emptied it. Other 5 services (auth, sender, parser, audience, notifier) retain their root `{svc}.constants.ts` — they hold cross-folder domain port Symbols (`LOGIN_PORT`, `CAMPAIGN_REPOSITORY_PORT`, etc.) that span inbound/ ↔ outbound/.
