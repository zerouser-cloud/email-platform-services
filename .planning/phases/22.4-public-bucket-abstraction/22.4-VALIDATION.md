# Phase 22.4 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
>
> Per `CLAUDE.md` ("Без тестов: Тестирование — отдельный следующий этап") and `REQUIREMENTS.md` Out-of-Scope row "Testing (unit/integration)" — this project has no automated test framework. Validation in this phase is built on two automatable layers + one manual layer:
>
> 1. **Build/lint/grep gates** — `pnpm build`, `pnpm lint`, and explicit `grep` acceptance criteria in each task verify contracts deterministically.
> 2. **Zod schema parse on boot** — missing `STORAGE_PUBLIC_URL` / `STORAGE_MAX_UPLOAD_BYTES` fails fast at service startup.
> 3. **Manual smoke HTTP round-trip** — running `pnpm start:native` + curl against smoke endpoints (22.3 contract, rewritten in 22.4-02).
>
> This is the project's sanctioned "Nyquist floor" — every task has an `<automated>` verify that is either a build, lint, or grep check. No watch-mode flags. No testing framework installed.
