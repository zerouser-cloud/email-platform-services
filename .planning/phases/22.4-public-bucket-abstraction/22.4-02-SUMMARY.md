# Phase 22.4 Plan 02: Apps migrated to SharedNamespaceModule — Summary

## One-liner

Parser и notifier композиции переключены с `PublicStorageModule` (22.5 facade) на `SharedNamespaceModule.forNamespace({namespace:'reports', contentType: PDF, token: SHARED_REPORTS})`; smoke controllers переписаны под `NamespacedStoragePort` с `Readable.from(buffer)` upload и `fetch(url)` 200 verification вместо устаревшего `getSignedUrl`; env файлы синхронизированы с `STORAGE_PUBLIC_URL` + `STORAGE_MAX_UPLOAD_BYTES`.

## What Was Built

### Task 1 — Composition rewiring + facade removal (commit `6b1cff9`)

**App-layer rewiring:**
- `apps/parser/src/infrastructure/storage/parser-storage.module.ts`: `BucketStorageModule.forBucket` → `PrivateStorageModule.forBucket` (rename per Plan 01, API 1:1).
- `apps/parser/src/infrastructure/storage/storage.module.ts`: отказ от `PublicStorageModule`; `imports` = `[ParserStorageModule, SharedNamespaceModule.forNamespace({namespace:'reports', contentType: CONTENT_TYPE.PDF, token: SHARED_REPORTS})]`. `REPORTS_NAMESPACE = 'reports'` — локальная константа (infrastructure-layer policy, не подтягивается в foundation).
- `apps/notifier/src/infrastructure/storage/storage.module.ts`: отказ от `PublicStorageModule`; единственный import — `SharedNamespaceModule.forNamespace({..., healthToken: PUBLIC_BUCKET_HEALTH})`. Именно notifier держит public-bucket readiness probe (single source of truth — parser не double-probit).

**Health controllers (Decision B):**
- `apps/parser/src/health/health.controller.ts`: удалён `PUBLIC_STORAGE_HEALTH` (parser больше не держит probe для public bucket'а); оставлен `PARSER_STORAGE_HEALTH`.
- `apps/notifier/src/health/health.controller.ts`: `PUBLIC_STORAGE_HEALTH` → `PUBLIC_BUCKET_HEALTH` (renamed token), `publicBucket.isHealthy('s3:public')` — если Garage теряет bucket `public`, `/health/ready` → 503.

**Foundation amendments:**
- `namespaced-storage.interface.ts`: `NamespaceOptions` получает optional `healthToken?: symbol`.
- `shared-namespace.module.ts`: если `opts.healthToken` задан, factory добавляет второй provider — `S3HealthIndicator(HealthIndicatorService, S3_CLIENT, PUBLIC_BUCKET)` на этом токене; добавляется `TerminusModule` в imports. Без healthToken — модуль не меняется (один provider для `opts.token`).
- `public.constants.ts`: удалён `PUBLIC_STORAGE` symbol (obsolete DI token); `PUBLIC_STORAGE_HEALTH` переименован в `PUBLIC_BUCKET_HEALTH` (semantic clarity — marker для публичного bucket probe, а не для модуля которого больше нет).
- `external/storage/index.ts`: добавлен `export type { PrivateStoragePort }` из `internal/storage` — type-only re-export по тому же шаблону что `StorageHealthIndicator`. Позволяет `apps/*/src/test/*.ts` аннотировать `@Inject(*_STORAGE)` без нарушения ESLint-правила `no-restricted-imports` (которое запрещает `@email-platform/foundation/internal` везде кроме `apps/*/src/infrastructure/**`).
- `public-storage.module.ts` физически удалён — barrel не реэкспортил его уже с Plan 01 Task 2.

### Task 2 — Smoke controllers + env sync (commit `9fa2223`)

**Parser smoke controller** — двухветочный cycle:
- Inject: `@Inject(PARSER_STORAGE) parserStorage: PrivateStoragePort` + `@Inject(SHARED_REPORTS) publicReports: NamespacedStoragePort`.
- Private cycle (`PARSER_STORAGE_BUCKET = 'parser'`): `upload(key, Buffer, 'text/plain')` → `exists(key)` → `download(key)` + equals-check. `getSignedUrl` шаг удалён (метода нет).
- Public cycle (`PUBLIC_BUCKET = 'public'`): `upload(filename, Readable.from(Buffer))` → `{url, key}` → `exists(key)` → `fetch(url)` ожидает status 200.
- Cleanup RPC диспатчит по `bucket`: `parser` → parserStorage.delete, `public` → publicReports.delete.

**Notifier smoke controller** — single public cycle:
- Inject: `@Inject(SHARED_REPORTS)` only.
- Cycle идентичен parser'овскому public cycle: upload(Readable) → exists → fetch(url) 200.
- Cleanup handles только `PUBLIC_BUCKET`.

**Constants extraction (no-magic-values):** в каждом smoke controller локальные `as const` объекты `SMOKE` (payload prefix, key prefix, ext, status_ok, content_type для parser) и `STEP` (upload/exists/download/public-get).

**Env files:**
- `.env` (local-native): `STORAGE_PUBLIC_URL=http://public.localhost:3902`, `STORAGE_MAX_UPLOAD_BYTES=104857600`.
- `.env.docker` (compose): `STORAGE_PUBLIC_URL=http://public.localhost:3902` (smoke-контроллеры ходят с host через published port; внутри-container S3 API трафик идёт через отдельный `STORAGE_ENDPOINT=garage:3900`, без изменений из 22.5), `STORAGE_MAX_UPLOAD_BYTES=104857600`.
- `.env.example` (prod-shape template): `STORAGE_PUBLIC_URL=https://public.garage.email-platform.pp.ua`, `STORAGE_MAX_UPLOAD_BYTES=104857600`.
- Все три значения вставлены непосредственно после `STORAGE_REGION=` — STORAGE_* блок остаётся contiguous.
- Значения следуют D-29: bucket `public` в hostname (virtual-host style per Garage `s3_web` config), порт 3902 (Garage web endpoint, НЕ 3900 который S3 API без anonymous read).

**Incidental prettier auto-fixes** (collateral from `pnpm lint:fix` run — required to keep `pnpm lint` exit 0):
- `apps/gateway/src/test/smoke-test.module.ts`, `apps/gateway/src/test/storage-smoke.controller.ts`: line-break formatting on multi-arg calls.
- `apps/parser/src/infrastructure/grpc/parser.grpc-server.ts`: one-line signature formatting.
- `packages/config/src/env-schema.ts`: single-line refinement message.

Эти файлы не были в исходном scope Plan 02, но лежали в workspace-wide lint:fix diff — без их коммита `pnpm lint` падает на prettier ошибках (которые существовали и на HEAD — но success criteria Plan 02 требует lint green). Включены как Deviation Rule 3 (Blocking).

## Smoke Controller Shape Diff Summary

**Before (22.3):**
```
Inject: StoragePort[] (parser + reports buckets, same port)
runSmokeCycle(storage, bucket):
  upload(key, Buffer, 'text/plain')
  exists(key)
  download(key)
  getSignedUrl(key, 300_000 ms)  ← presigner step
```

**After (22.4-02):**
```
Parser — two ports, two cycles:
  private: PrivateStoragePort (Buffer upload, no signed URL)
  public:  NamespacedStoragePort
    upload(filename, Readable.from(buffer)) → {url, key}
    exists(key)
    fetch(url) expects 200 OK                 ← replaces signed URL
Notifier — public only:
  Same three-step public cycle, no private bucket
```
