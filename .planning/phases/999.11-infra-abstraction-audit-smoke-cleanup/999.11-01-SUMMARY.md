## Decisions Made

- **OQ-1 disposition:** deleted `apps/gateway/src/infrastructure/clients/http-smoke/` atomically with the `test/http-smoke/` subtree in Commit 2. Phase 24.1 D-24/D-25 had split the client into infrastructure/ to survive a future admin-diagnostic phase; that phase is no longer on the roadmap (Phase 999.15 uses CI post-deploy smoke, not runtime deep-smoke). Zero remaining consumers post-Commit-1 made the split orphan dead weight worse than Phase 24.1 foresaw. D-03 "trivial downstream consequence" escape hatch applies — scope extension justified because deletion's ripple is mechanical (zero consumers, no external references).
- **Consumer-first commit order (D-04):** preserved verbatim, no reordering for "efficiency". Each commit closes a logical seam with green tsc + lint.
- **Empty directory handling (OQ-3):** no explicit `rmdir`, no `.gitkeep` stub. Git tracks files, not directories — empty dirs auto-fall-out from the tree representation.
- **Path-scoped staging:** every commit used `git add <explicit-paths>` or `git rm <explicit-paths>` — never `git add .` or `git add -A`. Working-tree noise (modified STATE.md, modified packages/foundation/.../promisify-grpc-client.ts, ~140 untracked .claude/* artifacts) was deliberately excluded from every commit.
