## Decisions Made

See `key-decisions` in frontmatter. Summary:

1. **Atomic Commit 6 bundling** (D-04 + Pitfall 1): 5 files in 1 commit. Alternative (3 sequential commits: proto edit → regen → stub removal) would produce a red-TS intermediate state because Commits N-1 and N would have either (a) stubs referencing deleted proto types, or (b) controller missing implementations for proto-declared RPCs. Single commit preserves bisect-green invariant.
2. **Pitfall 3 hardened in notifier.proto comment**: The service-level doc block now explicitly documents that a HealthCheck-only NotifierService is structurally valid, intentional, and out of scope for further cleanup. This protects against future reviewers flagging the "dead" proto for removal.
3. **OQ-2 resolution**: D-07 smoke ran as a SEPARATE gate post-Commit-6 (not amended into the commit). Both modes passed first try, so no follow-up was needed. If smoke had failed, the root cause would have been a new plan, not a Commit 6 amendment.
4. **Path-scoped staging**: `git add` targeted exactly the 5 target files; the pre-existing in-flight modification to `packages/foundation/src/external/grpc/clients/promisify-grpc-client.ts` (carry-over from Plan 02/03) was deliberately excluded, preserving Plan 02/03 precedent.
