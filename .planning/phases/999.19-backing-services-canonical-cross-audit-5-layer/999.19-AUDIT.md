### F-01 (major, L1): RedisCacheService.get<T>() — unchecked JSON cast + silent corruption swallow

- **ID:** F-01
- **Layer:** L1 cache (Redis)
- **Severity:** major
- **Title:** `RedisCacheService.get<T>(key)` returns `null` for both absent AND corrupt cache entries; unchecked `as T` cast loses runtime type-safety; corrupt key keeps polluting cache until TTL because the silent swallow has no `del()`/log side-effect. Caller cannot distinguish "absent" from "corrupt", and runtime values that drift from the generic `T` propagate into business code as a `TypeError` time-bomb.
- **Evidence:**

```bash
$ cat -n packages/foundation/src/external/cache/cache.service.ts | sed -n '16,26p'
    16    async get<T>(key: string): Promise<T | null> {
    17      const raw = await this.redis.get(this.prefixKey(key));
    18      if (raw === null) {
    19        return null;
    20      }
    21      try {
    22        return JSON.parse(raw) as T;
    23      } catch {
    24        return null;
    25      }
    26    }
# Two distinct defects in 11 lines:
# (1) line 22 — unchecked `as T` cast. JSON.parse returns `unknown`; cast ignores
#     runtime shape. No schema validation, no type guard, no zod parse.
# (2) lines 23-24 — silent swallow. `catch { return null }` with no log, no del(),
#     no metric. Corrupt entries collapse into the same `null` channel as absent
#     entries; caller cannot distinguish. Corrupt key persists until TTL.
```

```bash
$ grep -nE 'export interface CachePort' packages/foundation/src/external/cache/cache.interfaces.ts
3:export interface CachePort {
$ sed -n '3,7p' packages/foundation/src/external/cache/cache.interfaces.ts
export interface CachePort {
  get<T>(key: string): Promise<T | null>;
  set(key: string, value: unknown, ttlMs: number): Promise<void>;
  del(key: string): Promise<void>;
}
# Current Tier-1 port shape returns Promise<T | null> — `null` is overloaded
# as absent OR corrupt sentinel. Port itself bakes the information loss in.
```

- **Violated contract:** DESIGN.md I-1.6 (`clean-ddd-hexagonal` skill — Tier 1 port `CachePort.get<T>()` MUST honestly signal failure modes; `null`-overload as "absent OR corrupt" is dishonest port contract) + I-0.5 (`infrastructure-client-layering` skill — Tier 1/2/3 layering universal: Tier 1 abstraction MUST signal protocol failures back to caller, not silently swallow). Multi-skill cross-ref per D-A3.1: `composition-over-inheritance` (typed return shape via discriminated union or Result<T> rather than overloaded sentinel) is the structural fix axis.
- **Impact:** Every business consumer of cached structured data risks (a) runtime `TypeError: Cannot read property X of undefined` when cached value drifts from generic `T` (unchecked cast), or (b) silent stale-data bug — corrupt key returns `null` (absent) → callback re-fetches from source → re-caches potentially the same corrupted shape → repeats. Production hard to debug: no log line, no metric, no observable side-effect. Currently 0 business consumers of `CACHE_SERVICE` in `apps/*` (only gateway uses `REDIS_CLIENT` directly via throttle storage), so impact is contained TODAY but blocks any future business cache use until corrected.
- **Solution ref:** → SOLUTIONS.md F-01 (3-axis cartesian per CONTEXT.md D-A4 + RESEARCH §8.1: return-shape × schema-placement × corruption side-effect = 27 combinations; SOLUTIONS author picks 3-4 most relevant; recommended starting pick = discriminated union return + optional schema param + severity-aware del).

### F-05 (minor, L3): S3HealthIndicator no client-side timeout — parser /health/ready stalls 10s+ on Garage S3

Memory anchor `project_parser_health_s3_timeout` documents the symptom; the gateway aggregate path via gRPC is unaffected because the gRPC deadline interceptor short-circuits independently.
- **Evidence:**

    17      try {
    18        await this.client.send(new HeadBucketCommand({ Bucket: this.bucket }));
    19        return indicator.up();
    20      } catch {
    21        return indicator.down({ message: S3_HEALTH_CHECK.DOWN_MESSAGE });

NOT a violation of an L3 visibility/encapsulation invariant — pure operational/DX drift inside the body. RESEARCH §9.7 + memory anchor `project_parser_health_s3_timeout` flagged.
- **Impact:** Parser `/health/ready` HTTP probe latency = 10s+ instead of < 500ms on slow/partial Garage S3. Kubernetes readiness probe with default `timeoutSeconds: 1` would mark the pod NotReady transiently. Per memory anchor, gateway aggregate via gRPC is unaffected (deadline interceptor independently gates), but parser + notifier direct HTTP probes inherit the 10s+ stall.
