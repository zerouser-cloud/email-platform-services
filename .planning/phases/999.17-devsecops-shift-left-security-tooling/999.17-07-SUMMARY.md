#### `scripts/security/audit-if-lock-changed.sh` (mode 100755, ~30 lines)

```bash
#!/usr/bin/env bash
# Phase 999.17 — pnpm-audit guard clause (only runs if pnpm-lock.yaml changed vs origin/main).
# See .planning/phases/999.17-devsecops-shift-left-security-tooling/999.17-07-PLAN.md.
set -euo pipefail

RED='\033[0;31m'; GREEN='\033[0;32m'; YELLOW='\033[1;33m'; NC='\033[0m'

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
cd "$PROJECT_ROOT"

# Ensure origin/main is fetchable; fail soft if not (e.g. fresh clone, network blip)
if ! git rev-parse origin/main >/dev/null 2>&1; then
  echo -e "${YELLOW}  WARN${NC}: origin/main not resolvable; attempting fetch."
  git fetch origin main --depth=1 >/dev/null 2>&1 || {
    echo -e "${YELLOW}  SKIP${NC}: origin/main unreachable — skipping SCA gate (CI is enforcement layer per D-04)."
    exit 0
  }
fi

# Guard clause — early exit 0 if lockfile unchanged (per RESEARCH §Pattern 5 + PATTERNS §SP-3)
if git diff --quiet origin/main -- pnpm-lock.yaml; then
  echo -e "${GREEN}  SKIP${NC}: pnpm-lock.yaml unchanged vs origin/main; SCA not needed."
  exit 0
fi

# Lockfile changed — run pnpm audit (requires pnpm 11.x per D-11; v9/v10 returns HTTP 410)
echo -e "${GREEN}  RUN${NC}: pnpm-lock.yaml changed; running pnpm audit --audit-level high."
exec pnpm audit --audit-level high
```

#### `scripts/security/semgrep-diff.sh` (mode 100755, ~42 lines)

```bash
#!/usr/bin/env bash
# Phase 999.17 — Semgrep diff scan vs origin/main (D-13 explicit composition + D-16 Docker-wrapped).
# See .planning/phases/999.17-devsecops-shift-left-security-tooling/999.17-07-PLAN.md.
# Reads ruleset IDs from .semgrep.yml `rulesets:` field (Plan 04 product).
set -euo pipefail

RED='\033[0;31m'; GREEN='\033[0;32m'; YELLOW='\033[1;33m'; NC='\033[0m'

PROJECT_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
cd "$PROJECT_ROOT"

# Verify .semgrep.yml exists (Plan 04 product)
if [ ! -f .semgrep.yml ]; then
  echo -e "${RED}  FAIL${NC}: .semgrep.yml not found at repo root (Plan 04 prerequisite missing)."
  exit 1
fi

# Resolve baseline hash (RESEARCH §Pitfall 4 — flag wants hash, not ref)
if ! git rev-parse origin/main >/dev/null 2>&1; then
  echo -e "${YELLOW}  WARN${NC}: origin/main not resolvable; attempting fetch."
  git fetch origin main --depth=1 >/dev/null 2>&1 || {
    echo -e "${YELLOW}  SKIP${NC}: origin/main unreachable — skipping Semgrep diff (CI is enforcement layer per D-04)."
    exit 0
  }
fi
BASELINE="$(git rev-parse origin/main)"

# Parse ruleset IDs from .semgrep.yml `rulesets:` field, emit --config flags
# Convention from Plan 04: each ruleset listed as `  - p/<id>` under `rulesets:` key
RULESET_FLAGS=()
while IFS= read -r ruleset_id; do
  RULESET_FLAGS+=(--config "$ruleset_id")
done < <(grep -E '^\s+- p/' .semgrep.yml | awk '{print $2}')

if [ ${#RULESET_FLAGS[@]} -eq 0 ]; then
  echo -e "${RED}  FAIL${NC}: no rulesets parsed from .semgrep.yml (expected lines like '  - p/typescript')."
  exit 1
fi

echo -e "${GREEN}  RUN${NC}: Semgrep diff vs $BASELINE with ${#RULESET_FLAGS[@]} ruleset(s) (Docker-wrapped, returntocorp/semgrep:1.50)."
exec docker run --rm \
  -v "$(pwd):/repo" -w /repo \
  returntocorp/semgrep:1.50 \
  semgrep scan "${RULESET_FLAGS[@]}" --baseline-commit "$BASELINE" --error
```

## Decisions Made

- **Trivy tag pin level — 0.50.4 patch, not 0.50 major.minor.** Plan called for `aquasec/trivy:0.50` per D-14 + D-16. Docker Hub registry only publishes full SemVer tags for `aquasec/trivy`; `0.50` does not resolve (`manifest unknown`). Available 0.50.x tags: 0.50.0, 0.50.1, 0.50.2, 0.50.4 (no 0.50.3, no 0.50 alias). Closest valid pin within the same minor is `0.50.4` (latest patch). Mirrors Plan 06's identical fix for gitleaks (`v8.30 → v8.30.1`). Honors D-14 + D-16 intent (reproducible, in-minor pinning) while remaining a resolvable tag. Tightening pin to patch is fail-safe for security tooling. Same operational cadence (1-character edit + code review for tag bumps).
- **Semgrep tag — kept at `1.50` exactly.** Direct test `docker pull returntocorp/semgrep:1.50` succeeded; Semgrep DOES publish minor aliases. Asymmetric registry convention (semgrep yes, trivy no) is real and per-image; per-image deviation is correct.
- **Soft-fail on `git rev-parse origin/main` failure.** Fresh clones / network blips skip the SCA + IaC + Semgrep-diff gates with WARN (exit 0). CI is enforcement layer per D-04. Bounded failure mode: developer subsequently runs `git fetch` (or hits a network), gates fire normally on next push.
- **Order of `&&` chain.** typecheck → env-parity → semgrep-diff → audit-if-lock-changed → trivy-config-if-changed. Cheap-fail-first ergonomics: TS errors common (no Docker pull cost), pure bash second (no Docker), Docker-pull-on-first-run third, guard-clauses last (often skip → cheap).
- **Insertion point in package.json = after `security:secrets-staged`, before `prepare`**: keeps all 8 `security:*` entries grouped contiguously, preserves Plan 06 ordering, keeps `prepare: husky` as last entry (npm `prepare` lifecycle convention).
