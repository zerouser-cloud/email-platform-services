### `package.json` (modified — add `security:*` scripts namespace + `lint-staged` devDep)

**Analog:** `package.json` (current state, lines 6–27)

**Existing scripts patterns to mirror:**

```json
"scripts": {
  "build": "turbo run build",
  "lint": "turbo run lint",
  "typecheck": "turbo run typecheck",
  "check-arch": "bash scripts/check-architecture.sh",
  "start:native": "pnpm infra:up && pnpm dev",
  "start:isolated": "pnpm docker:up",
  "infra:up": "docker compose --env-file .env.docker -f infra/docker-compose.infra.yml ... up -d",
  "storage:bootstrap": "bash infra/docker/storage-bootstrap.sh",
  "prepare": "husky"
}
```

**Patterns to copy:**

1. **Namespace prefix with `:` separator** — `start:native`, `start:isolated`, `infra:up`, `infra:down`, `docker:up`. Apply: `security:pre-commit`, `security:pre-push`, `security:env-parity`, `security:secrets-staged`, `security:semgrep-diff`, `security:typecheck`, `security:trivy-config`, `security:audit`. (D-02 + research §Pattern 1.)
2. **Composition via `pnpm` not raw shell** — `start:native: pnpm infra:up && pnpm dev`. Orchestrator scripts chain other npm-scripts. Apply: `security:pre-push`: `pnpm run security:typecheck && pnpm run security:env-parity && pnpm run security:semgrep-diff && pnpm run security:audit && pnpm run security:trivy-config`.
3. **`bash scripts/<name>.sh` for shell delegation** — `check-arch`, `storage:bootstrap`. Apply: `security:env-parity`: `bash scripts/check-env-parity.sh` (D-10 wraps unchanged).
4. **`turbo run <task>` for monorepo tasks** — `lint`, `typecheck`. Apply: `security:typecheck`: `turbo run typecheck`. NEVER add `tsc` to lint-staged (research Pitfall 2).
5. **`prepare: husky` (line 26) — DO NOT TOUCH** (research Runtime State Inventory; A8 verified).

**`devDependencies` (lines 28–39) — add ONE entry, caret-major pin matching existing style:**

```json
"lint-staged": "^16.4.0"
```

No other npm packages — gitleaks/Semgrep/Trivy are system binaries (or Docker-wrapped per D-16).

**Anti-pattern from existing code:** `&&` chain, fail-fast. NOT `;`. Apply same. Conditional steps (lockfile-changed, Dockerfile-changed) extract to `scripts/security/<name>.sh` mirroring `check-env-parity.sh` shape.

- Section 2: project allowlist — gitleaks `[allowlist]` ↔ ESLint `overrides`.

TOML format is library-dictated (no in-repo TOML precedent). Use research §Code Examples body verbatim:
