# Phase 999.17 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution. This phase is **scaffold + document**: no business logic, no unit tests. Verification is artifact-shape (file exists, valid YAML/JSON, matches expected pattern) + behavioral hook tests (hook fires, hook fails on bad input, hook passes on good input).

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | None (scaffold + document phase). Verification = bash assertions in shell scripts + manual smoke. |
| **Config file** | none |
| **Quick run command** | `pnpm run lint && pnpm run typecheck` (existing) + `bash scripts/check-env-parity.sh` |
| **Full suite command** | `pnpm run security:pre-commit && pnpm run security:pre-push` (after this phase ships) — runs all hooks against current repo state |
| **Estimated runtime** | Quick: ~5-8s. Full: ~30-60s (includes Docker pulls on first run). |

---

## Sampling Rate

- **After every task commit:** Verify the artifact created by that task exists with expected shape (frontmatter, key fields, valid syntax).
- **After every plan wave:** Run all hook scripts manually against current commit; verify no false-positive failures.
- **Before `/gsd-verify-work`:** Full dual-runtime smoke (`pnpm start:native` + `pnpm start:isolated`) must remain green — security tooling MUST NOT break the existing runtime.
- **Max feedback latency:** 60s (one Docker pull + one full hook execution).
