<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renovate runner ↔ npm registry / OSV.dev | Runner queries registries for new versions + OSV for malicious-package alerts; HTTPS, public APIs |
| Renovate runner ↔ project repo | Runner has write access (creates branches, opens PRs); access scoped via GitHub App permissions OR GitLab Renovate runner token |
| `renovate.json` config ↔ Renovate runtime | Config interpreted at every Renovate run; mis-config could open unwanted PRs OR fail to flag vulnerabilities |
| Bot dormancy ↔ activation | Config exists in repo but bot does not run until DevOps activates (D-08 explicit) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99917-08-01 | Tampering | Malicious npm package introduced via dependency update PR | mitigate | `osvVulnerabilityAlerts: true` (OSV checks) + `minimumReleaseAge: "14 days"` (waits for community to flag) + `automerge: false` (human review). Defense in depth. |
| T-99917-08-02 | Elevation of Privilege | Renovate auto-merges a compromised security PR | mitigate | `automerge: false` is the explicit guard. Acceptance criterion enforces. Future tuning (selective automerge for trusted patch updates) deferred to post-DevOps-activation. |
| T-99917-08-03 | Information Disclosure | Renovate runner has excessive repo access | accept | Permission model is DevOps-side (GitHub App scope OR GitLab project token). `renovate.json` itself does not grant permissions. Documented in DEVOPS-HANDOFF.md (Plan 09) Renovate activation section. |
| T-99917-08-04 | Tampering | Deprecated `config:base` produces dashboard warnings | mitigate | Acceptance criterion: `grep -c '"config:base"' renovate.json` equals 0. Use `config:recommended` per RESEARCH §Pitfall 7. |
| T-99917-08-05 | Denial of Service | Renovate floods repo with PRs (unbatched updates) | mitigate | `packageRules` batches: monorepo internal grouping + weekly patch batch. `lockFileMaintenance` weekly only. `automerge: false` keeps PR queue under human control. |
