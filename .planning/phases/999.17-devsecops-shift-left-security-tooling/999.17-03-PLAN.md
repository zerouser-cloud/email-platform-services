```
# Phase 999.17 — gitleaks suppression baseline. Body intentionally empty.
# See .planning/phases/999.17-devsecops-shift-left-security-tooling/.
#
# .gitleaksignore — fingerprints of secret findings to ignore.
#
# FORMAT:  <commit-sha>:<file-path>:<rule-id>:<line-number>
# EXAMPLE: cd5226711335c68be1e720b318b7bc3135a30eb2:apps/auth/test/fixture.ts:generic-api-key:42
#
# RULES:
# 1. Every entry MUST have a comment line above it explaining WHY it is ignored.
# 2. Comment must include: (a) reason it's a false positive OR (b) ticket
#    link if it's an accepted risk, AND (c) re-evaluate-by date if accepted.
# 3. Secrets are ALWAYS preferred to be rotated, not ignored. Add an entry
#    here only after rotation is impossible AND the value is verified to be
#    a fixture / test data / non-production.
# 4. Empty file = clean state. Do not add entries proactively.
```
