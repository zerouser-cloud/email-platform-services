## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | TypeScript compiler (`tsc`) + ESLint — no unit test framework per project constraint (structural refactor phase) |
| **Config file** | `tsconfig.base.json` (workspace), per-app `tsconfig.json`; `.eslintrc.js` (workspace root) |
| **Quick run command** | `pnpm --filter=@email-platform/foundation typecheck` (for foundation touches) / `pnpm --filter=@email-platform/<app> typecheck` (for app touches) |
| **Full suite command** | `pnpm build && pnpm lint` |
| **Estimated runtime** | ~20 seconds quick typecheck, ~60 seconds full suite |
| **Runtime smoke** | Native: `pnpm stop:native && pnpm start:native`, then `curl http://localhost:3000/health/ready`. Isolated: `pnpm stop:isolated && pnpm start:isolated`, then same curl. |

---

## Sampling Rate

- **After every task commit:** Run quick typecheck for the directly-touched package (`pnpm --filter=<package> typecheck`); for ESLint-guard-related changes also run `pnpm lint`.
- **After every plan wave:** Run `pnpm build && pnpm lint` (full workspace) + targeted runtime smoke per D-12/D-13/D-14 (pilot + sweep + final smoke).
- **Before `/gsd-verify-work`:** Full suite must be green; BOTH `pnpm start:native` AND `pnpm start:isolated` reach healthy `/health/ready` end-to-end including cross-service sender→audience, parser→notifier, audience→parser probes.
- **Max feedback latency:** ~60 seconds (full build + lint); runtime smoke adds ~1-3 minutes per flow.
