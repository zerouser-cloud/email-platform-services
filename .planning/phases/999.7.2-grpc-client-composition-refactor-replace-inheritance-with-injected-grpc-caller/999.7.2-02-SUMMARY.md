## Accomplishments

- **Rewrote `apps/gateway/src/infrastructure/clients/auth/auth.client.ts`** from a 37-line `extends AbstractGrpcClient<AuthProto.AuthServiceClient>` shape (3-arg constructor calling `super(...)`, 7 methods using `this.call(m, this.raw.m(r, this.buildMetadata(o)))`) to a 36-line plain ES class:
  - Imports: DROPPED `ClsService` (nestjs-cls), DROPPED `AbstractGrpcClient` (foundation), COMBINED type imports to `import type { GrpcCaller, CallOpts } from '@email-platform/foundation'`
  - Class head: no `extends`, added `private readonly raw: AuthProto.AuthServiceClient` field
  - Constructor: `(grpcClient: ClientGrpc, private readonly grpc: GrpcCaller)` positional params; body `this.raw = grpcClient.getService<AuthProto.AuthServiceClient>(SERVICE.auth.grpc.serviceName)` per D-11 (Pitfall 3 obsolete — `getService()` is synchronous proto-lookup, safe under `useFactory`)
  - 7 method bodies mechanically rewritten: `return this.grpc.call('<methodName>', opts, (m) => this.raw.<methodName>(req, m))` — signatures preserved, parameter renamed `request` → `req` (cosmetic, matches RESEARCH pilot snippet L825-864)

- **Modified `apps/gateway/src/infrastructure/clients/auth/auth-client.module.ts`** — one-line change to the `defineGrpcClient.build` callback:
  - BEFORE: `(grpcClient, cls, deadlineMs) => new AuthClient(grpcClient, cls, deadlineMs),`
  - AFTER: `(grpcClient, caller) => new AuthClient(grpcClient, caller),`
  - Named re-exports `AUTH_CLIENT_GRPC` and `AUTH_GRPC_HEALTH` (999.7.1 D-06) preserved verbatim. `@Module({})` class + `forRoot()` body preserved verbatim.

- **Verified gateway->auth typecheck path compiles end-to-end**: `pnpm --filter=@email-platform/gateway typecheck` now reports ZERO errors originating in `apps/gateway/src/infrastructure/clients/auth/` — all remaining diagnostics are in the 4 siblings (`audience/`, `notifier/`, `parser/`, `sender/`) reserved for Plan 03a.
