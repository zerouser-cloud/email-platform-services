Plan 08 использовал `stage: verify` ПОСЛЕ `stage: build` → topological order гарантирован, но добавляем явный `needs:` для skip-on-build-fail и параллельной optimization.

**FR-16 Substitutability Rule preserved:** invocation = `bash scripts/verify-multiarch-manifests.sh ...` — это direct bash, не embedded shell logic. Также допустимо `pnpm verify:multiarch -- "${CI_REGISTRY_IMAGE}/..."` (npm-script с position args) — оба валидны. Direct bash проще для CI verbosity.
