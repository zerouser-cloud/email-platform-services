**Honest framing:**

- **Drop-husky-style canon empirically HOLDS:** 5 of 7 major frameworks (React, Astro, Remix, Nuxt, SvelteKit) — all top-tier, MAANG-adjacent or large-community-backed — use **CI-only enforcement, no Git-hooks-via-npm-lifecycle**.

Confirms §B.2.4: Vercel-deployed projects don't deploy через Docker monorepo, so they accept pnpm bug #7068 exposure differently. **Their pattern is canonical для their context (Vercel platform deploy), not для self-hosted Kubernetes deploy через Dockerfile.**
