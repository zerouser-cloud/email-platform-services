## Decisions Made

См. `key-decisions:` в frontmatter. Ключевые:

1. **Fix root cause, не bypass guard.** SKIP guard в verifier scripts — корректное поведение для local dev на машинах без docker. Решение: предоставить docker через docker:24 + dind в CI, не модифицировать скрипт.
2. **Direct bash invocation с position arg вместо `pnpm verify:multiarch ARG`.** npm-script wrapper неудобен для CI quoting — direct bash transparent и соответствует FR-16 substitutability rule.
3. **Canonical representative auth для multi-arch проверки.** Все 6 services используют один Dockerfile + одинаковый buildx setup → проверять multi-arch manifest для одного service достаточно. Auth выбран как первый сервис в alphabetical/canonical order.
4. **`needs: [job: build, artifacts: false]` явно.** Топологический order через stages: гарантирует, что verify-multiarch выполняется ПОСЛЕ build, но `needs:` добавляет skip-on-build-fail behavior + parallel optimization.
