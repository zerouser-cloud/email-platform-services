Create `defineGrpcClient()` factory function in foundation that encapsulates the ~60-line gRPC client module boilerplate (ClientsModule.registerAsync, health indicator provider, facade provider, deadline interceptor) into a reusable helper. Analogous to `httpClientProvider()` from Phase 24.1, but returning `{ imports, providers, exports }` instead of a single Provider (gRPC needs ClientsModule and TerminusModule as imports).

Purpose: This factory is the prerequisite for Plans 02-03 which move per-service client modules from foundation into apps/. Without it, each consumer would duplicate 60 lines of identical boilerplate.

Output: `define-grpc-client.ts` in foundation + barrel update.

Create `packages/foundation/src/external/grpc/clients/define-grpc-client.ts` with the following content:

1. Export interface `DefineGrpcClientOpts`:
   - `readonly service: GrpcServiceDeclaration` (from `@email-platform/config`)
   - `readonly clientToken: symbol` — DI token for the typed facade (typically `SERVICE.x.diToken`)
   - `readonly healthToken: symbol` — DI token for the health indicator (e.g. `AUTH_GRPC_HEALTH`)
   - `readonly grpcToken: symbol` — DI token for the raw `ClientGrpc` instance (e.g. `AUTH_CLIENT_GRPC`)

2. Export interface `GrpcClientBuildResult`:
   - `readonly imports: DynamicModule[]`
   - `readonly providers: Provider[]`
   - `readonly exports: symbol[]`

3. Export function `defineGrpcClient(opts, build)`:
   - Signature: `function defineGrpcClient<T extends object>(opts: DefineGrpcClientOpts, build: (grpc: ClientGrpc, cls: ClsService, deadlineMs: number) => T): GrpcClientBuildResult`
   - The `build` callback is called by the consumer (who legitimately imports contracts). This function does NOT import contracts.
   - Returns object with:

   **imports:** Array containing:
   - `TerminusModule` (from `@nestjs/terminus`)
   - `ClientsModule.registerAsync([{ name: opts.grpcToken, inject: [ConfigService], useFactory: (config) => ({ transport: Transport.GRPC, options: { url: config.get<string>(opts.service.envKeys.GRPC_URL!)!, package: [opts.service.grpc.package, GRPC_CLIENT_HEALTH.PACKAGE], protoPath: [resolveProtoPath(opts.service.grpc.package, config.get<string>('PROTO_DIR')!), require.resolve('grpc-health-check/proto/health/v1/health.proto')], channelOptions: { interceptors: [createDeadlineInterceptor(config.get<number>('GRPC_DEADLINE_MS')!)] } } }) }])`

   **providers:** Array containing:
   - Facade provider: `{ provide: opts.clientToken, inject: [opts.grpcToken, ClsService, ConfigService], useFactory: (grpc, cls, config) => build(grpc, cls, config.get<number>('GRPC_DEADLINE_MS')!) }`
   - Health provider: `{ provide: opts.healthToken, inject: [HealthIndicatorService, opts.grpcToken], useFactory: (his, grpc) => new GrpcClientHealthIndicator(his, grpc) }`

   **exports:** `[opts.clientToken, opts.healthToken]`
