Create per-upstream gRPC client directories in 3 cross-service apps (sender->audience, parser->notifier, audience->parser) and wire them into root modules. Each cross-service app has exactly one upstream gRPC dependency, so no GrpcClientsModule compositor is needed — the root module imports the client module directly.

Purpose: Completes the consumer-side migration for all non-gateway apps, making foundation's per-service client exports fully redundant.

Output: 12 new files (3 services x 4 files each) + 3 modified root modules.
</objective>
