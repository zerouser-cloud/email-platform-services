<objective>
Add two npm scripts (`reset:native`, `reset:isolated`) that mirror the existing `stop:*` counterparts but pass `--volumes` to `docker compose down`, so clean-slate testing flows can nuke all compose-managed volumes in one command. Document them in the two local sections of the bucket-provisioning runbook as the canonical "reset to clean state" workflow, preserving the manual `garage:bootstrap` step (Phase 22.5 D-05/D-06 philosophy: bootstrap is explicit, never auto-chained).

Purpose: Close the gap between stop (keeps volumes, preserving state) and full reset (needed when iterating on Garage layout, bucket provisioning, or schema changes during local dev/testing). Without `reset:*`, developers either run raw `docker compose ... down --volumes` (violating the "always use pnpm scripts" memory) or manually `docker volume rm` entries (error-prone).

Output: 2 new npm scripts in `package.json`; brief reset subsections added to Local-native (§1) and Local-isolated (§2) of the runbook.
</objective>
